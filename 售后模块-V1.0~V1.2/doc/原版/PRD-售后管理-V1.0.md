# 4. 详细需求

## 4.1. 商城运营后台系统

### 4.1.1. 售后管理模块

#### 4.1.1.1. 售后列表页

##### 1. 功能概述

- **功能描述**：售后列表页用于集中展示并处理仅退款、退货退款、换货三类售后售后单。
- **业务描述**：商家人员可在同一列表完成审核、驳回、审核退回地址、查看客户已填写物流、商家收货、执行退款、查看详情，避免跨页面切换。
- **使用角色**：售后运营、客服、财务人员。
- **触发条件**：从商城运营后台进入“售后管理 > 售后列表”。

###### 3.2 业务规则

| 规则编号 | 规则名称 | 适用场景 | 规则描述 | 错误提示 |
|----------|----------|----------|----------|----------|
| RULE-AF-001 | 驳回备注必填 | 驳回售后申请 | 点击“驳回并备注”后必须填写驳回原因才可提交 | 请先填写驳回备注 |
| RULE-AF-002 | 退回地址完整性 | 退货退款/换货审核 | 选择“需要退回商品”后，必须填写完整的详细地址、收件人、收件人手机号 | 请填写完整的详细地址、姓名和电话 |
| RULE-AF-003 | 寄回物流完整性 | 客户填写寄回物流/运营补录 | 物流公司与寄回单号必须同时填写 | 请填写完整物流信息 |
| RULE-AF-004 | 退货退款直退 | 退货退款审核 | 允许选择“无需退回商品，直接退款”，跳过寄回与确认收货节点 | - |
| RULE-AF-005 | 换货后二次售后 | 换货成功售后单 | 换货完成后可再次创建退货退款或仅退款售后单 | - |
| RULE-AF-006 | 退货单生成时机 | 退款成功回写 | 仅当支付渠道回调成功并确认退款成功后，且售后类型为「退货退款」或「换货」时，系统才自动生成退货单；「仅退款」不生成退货单 | - |
| RULE-AF-007 | 退款状态语义 | 退款处理链路 | `待退款` 表示待发起退款；`退款中` 表示已发起退款请求、等待支付渠道异步回调 | - |
| RULE-AF-008 | 退回地址优先级 | 退货退款/换货审核 | 优先使用供应商已配置并回传的退回地址；仅当供应商无地址时，才允许商家人工填写 | - |
| RULE-AF-009 | 客户物流自动流转 | 待买家退货 | 客户在 C 端填写完整物流公司与寄回单号后，售后单自动流转到”待商家收货” | - |
| RULE-AF-010 | 换货生成退货单时机 | 仓库确认收货 | 走换货流程时，当仓库确认收货后立即生成退货单，用于记录退货商品信息 | - |
| RULE-AF-011 | 换货自动确认收货 | 待客户收货 | 换货商品发出后，快递单号回传之日起10天内客户未确认收货，系统自动确认为换货成功 | - |

| PENDING_AUDIT | 待商家审核 | 新建售后售后单，等待商家审核 |
| WAIT_CUSTOMER_RETURN | 待买家退货 | 已审核通过，等待买家退货 |

##### 4. 交互设计

###### 4.1 交互说明

1. 运营可通过顶部审核状态按钮快速过滤售后单：「待审核」显示首次审核未操作的售后单（状态为待商家审核）；「审核通过」显示首次审核已通过的售后单（不论后续处于退款中、退款成功、换货成功等任何状态）；「驳回」显示首次审核被驳回的售后单。筛选区的「售后状态」和「审核状态」下拉框与按钮联动。
2. 查询区域默认展示主订单号、子订单号、商品名称 3 个快捷筛选项；点击”展开”后按一行 4 项展示全部筛选条件（售后单号、SKU物流编码、供应商、收货人手机号、申请售后时间、售后状态、审核状态、售后类型、渠道），且”收起 / 重置 / 查询”与最后一行筛选项同行。
3. 点击”查看详情”后，以弹窗方式查看售后单基础信息（含商品图片占位）和审核轨迹（含操作人）。
4. 退货退款审核点击”通过审核”后，弹出二次确认弹窗，可选填备注（非必填）；确认后选择是否需要退回商品。
5. 若需要退回商品，系统优先带出供应商退回地址；若供应商无地址，则由商家人工填写并确认。退回地址需填写完整省份、城市、详细地址、收件人、手机号。
6. 在”待买家退货”状态下，客户于 C 端填写完整物流公司与寄回单号后，售后单自动流转到”待商家收货”；商家也支持在后台补录。
7. 在”待商家收货”状态下，退货退款点击”商家收货”进入”待退款”，换货点击”商家收货”进入”待仓库发货”。
8. 在”待退款”状态下，点击”执行退款”后弹出二次确认弹窗，确认后售后单进入”退款中”，等待支付渠道异步回调。
9. 支付渠道回调成功后流转为”退款成功”；回调失败后流转为”退款失败”，允许重新发起退款（需二次确认）。
10. 换货成功后，操作区新增”申请退货退款””申请仅退款”入口，自动创建二次售后售后单。
11. 在”待仓库发货”状态下，点击”仓库发货”后弹出登记发货单号弹窗，填写物流单号后确认发货。
12. 仅退款审核通过时，弹出二次确认弹窗（含退款说明），确认后直接进入退款流程。

### 4.1.2. 退货单列表页

#### 4.1.2.1. 功能概述

- **功能描述**：退货单列表页展示退款成功后系统自动生成的退货单，用于跟踪退货处理进度与供应链协同状态。
- **业务描述**：仅「退货退款」和「换货」类型的售后售后单在退款成功后自动生成退货单，「仅退款」不生成退货单。退货单关联退款单与售后单，形成完整追溯链路。
- **使用角色**：售后运营、供应链管理人员。
- **触发条件**：从商城运营后台进入"售后管理 > 退货单列表"。
