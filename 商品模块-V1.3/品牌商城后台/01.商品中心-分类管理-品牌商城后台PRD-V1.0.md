## 1. 文档概述

### 1.1 项目背景

商城运营平台（商品中心）负责分类结构编排、商品关联、渠道指定和推荐排序，通过发布机制将平台数据推送至各品牌商城后台。品牌商城后台作为各商城的独立管理端，接收平台数据后需进行二次编排——新增营销分类、编辑平台分类名称/图标、隐藏不适用的平台分类，调整最终排序，并通过小程序端预览确认 C 端展示效果。

当前品牌商城后台尚无独立的前台分类管理能力，商城工作人员无法在平台之上做差异化调整。

### 1.2 项目目标

1. **接收与展示平台数据**：接收商品中心推送的分类平台数据（基础分类 + 营销分类），在统一列表中展示，区分"平台"与"自有"来源。
2. **二次编排能力**：商城工作人员可在平台之上新增营销分类、编辑平台分类名称/图标、隐藏不适用的平台分类，调整最终排序。
3. **小程序端预览**：编辑完成后可预览小程序端 C 端分类展示效果。

### 1.3 核心术语

| 术语 | 定义 |
|------|------|
| **平台数据** | 商品中心发布推送的分类数据，品牌商城后台不可删除仅可隐藏 |
| **自有数据** | 品牌商城后台自行创建的营销分类，可增删改 |
| **基础分类** | 商品中心编排的前台导航分类（含系统类目节点和虚拟分类），商城侧不区分来源统一归为基础分类 |
| **营销分类** | 商品中心或商城侧创建的主题活动分类（如"618专区"），商城侧可新增 |
| **分类类型** | 统一列表通过"分类类型"列区分：基础分类 / 营销分类 |
| **来源** | 标识数据来源：平台（商品中心推送）/ 自有（商城自有） |

### 1.4 与商城运营平台的职责边界

| 维度 | 商城运营平台（商品中心） | 品牌商城后台 |
|------|----------------------|------------|
| 分类结构 | 编排分类结构、关联商品、指定适用渠道 | 接收平台，新增营销分类，编辑名称/图标，隐藏分类 |
| 发布机制 | 草稿/发布隔离，发布推送至品牌商城 | **直接生效**，预览小程序 C 端展示 |
| 删除权限 | 可删除虚拟分类和营销分类 | **不可删除平台分类**（仅可隐藏）；可删除自有营销分类 |
| 新增权限 | 可新增基础分类和营销分类 | **仅可新增营销分类**，不可新增基础分类 |
| 排序 | 设置推荐排序（推送后为初始值） | 可覆盖调整，最终排序以商城侧为准 |
| 修改平台分类 | 全部字段可编辑 | 仅可编辑名称和图标 |
| 渠道 | 为分类指定适用渠道 | 不涉及渠道配置，仅管理本商城数据 |

## 2. 功能架构

### 2.1 导航与布局

- **导航**：在系统左侧导航栏设置【前台分类管理】二级菜单，位于"商品管理"分组下。
- **整体布局**：采用"左侧分类树 + 右侧数据表格"布局（与商城运营平台前台分类管理保持一致）。

页面从左到右、从上到下分为以下区域：

| 区域 | 说明 |
|------|------|
| 左侧分类树 | 展示全部分类节点（基础分类 + 营销分类分区展示），顶部提供"全部 / 显示"两种筛选切换；点击节点过滤右侧表格，并记录选中节点供新建时自动填所属上级 |
| 右上角页面标题区 | 【预览】按钮 + 「上次同步时间」文字 |
| 右侧筛选栏 | 分类名称、分类类型、来源、C端展示状态筛选 + 查询/重置按钮（位于操作栏上方） |
| 右侧操作栏 | 左侧【新建营销分类】主按钮；右侧【全部展开 ▾ / 全部收起 ▴】链接（位于筛选栏下方、紧贴表格） |
| 右侧主体 | 统一分类数据表格（树形缩进展示） |

## 3. 核心功能说明

### 3.1 统一分类列表

**功能描述**

品牌商城后台的前台分类管理页面采用**统一列表**（不做基础/营销双Tab），通过"分类类型"列和"来源"列区分不同分类。这是与商城运营平台的核心交互差异。

**列表字段**

| 列 | 说明 |
|----|------|
| 分类名称 | 树形缩进展示（**强制三级结构**：一级=目录、二级=目录、第三级=节点可关联商品），行首展开箭头 + 拖拽手柄（⋮⋮，hover 显示）+ 分类名称。平台数据行使用浅灰色区分 |
| 分类类型 | `基础分类`（蓝）/ `营销分类`（橙） |
| 来源 | `平台`（灰）/ `自有`（绿） |
| 图标 | 缩略图（取分类名首字占位）。**仅第三级节点可上传图标**；一二级目录无图标 |
| 关联商品数 | 格式"在售数/总数"（如 45/58），纯文本展示。**仅第三级节点显示商品数**；一二级目录显示"—" |
| 排序 | 数字权重（越小越靠前），支持**行内点击编辑**或**拖拽排序**。商城侧排序为最终排序 |
| C端展示状态 | 开关控件。平台分类：显示/隐藏；自有分类：显示/隐藏 |
| 更新人/时间 | 审计信息，分两行展示（更新人 + 时间） |
| 操作 | 平台分类：操作列置空（平台维护，商城侧不可编辑/删除）；自有营销分类：【编辑】【删除】 |

> 说明：商品与分类的关联关系不在本页面维护。商品通过「商品中心 - 批量映射」上传映射表格自动归属对应分类，单个商品分类可在「商品中心」编辑商品时修改其前台分类字段。

### 3.2 接收平台数据

- 商品中心发布更新后，品牌商城后台自动接收新版本平台数据。
- 新推送的分类默认可见（除非商城侧此前已将其隐藏）。
- **商城侧已有的隐藏/排序调整保留**，不被新平台覆盖。

### 3.3 新建营销分类

- 点击操作栏【新建营销分类】，弹出新建弹窗。
- **不可新建基础分类**，弹窗中无此选项。
- 弹窗字段：

| 字段 | 控件 | 必填 | 说明 |
|------|------|:----:|------|
| 分类名称 | 文本输入 | 是 | 限制 50 字以内 |
| 所属上级 | **树状结构选择**（非下拉） | 否 | 弹窗内以树形列表展示可选上级（仅列出"自有"的一级、二级营销分类，三级节点不可作为上级）；支持点击选择；不选则为一级分类 |
| 节点类型 | **只读显示**（按层级自动判定，不可手选） | 是 | 一级=目录、二级=目录、第三级=节点（可关联商品）。由所选所属上级层级自动决定，弹窗中只读展示 |
| 分类图标 | 图片上传 | 否 | **仅当新建为第三级节点时可上传**；新建为一二级目录时不显示图标区 |

- **所属上级自动填联动**：在左侧分类树或右侧表格中点击选中某个节点后，再点击【新建营销分类】时，所属上级自动选中该节点（树状选择器中高亮）。前提是该节点为"自有"的一级或二级营销分类。

- **新建层级约束**：因强制三级结构，所选所属上级为一级时新建二级（目录）、为二级时新建三级（节点）；不可在第三级节点下继续新建子级。

- **分类名称查重规则**：
- **分类名称查重规则**：
  - **分类名称全局唯一**：平台分类之间、自有分类之间、平台与自有之间，均**不允许重名**（全树范围，含所有层级；忽略大小写、去首尾空格后比对）。
  - 输入时实时校验，命中重复时输入框下方红色提示"分类名称「XXX」已存在（平台/自有分类均不可重名），请修改"，并**阻断保存**。

### 3.4 平台分类（不可编辑）

- **平台来源的分类，商城侧不可编辑、不可删除**。操作列为空（无编辑、删除入口）。
- 平台分类的名称、图标、分类类型、来源、关联商品、所属上级、适用渠道等所有字段均由商品中心维护，商城侧只读。
- 商城侧仅可对平台分类执行：**隐藏/恢复**（控制 C 端展示状态）、**调整排序**。
- **名称覆盖策略**：商品中心再次发布时同步更新平台分类名称、图标等。

### 3.5 隐藏与恢复

- 商城可隐藏任意平台分类（基础或营销分类），隐藏后 C 端不可见但后台数据保留。
- 隐藏通过操作列或 C 端展示状态开关切换，即时生效。
- 商品中心再次发布时，商城侧隐藏状态保留。
- **不可操作**：商城不可删除平台分类（操作列无删除按钮）。

### 3.6 排序

商城侧提供两种调整排序的方式，调整后直接生效，最终排序以商城侧为准：

| 方式 | 操作 |
|------|------|
| 行内编辑 | 点击「排序」列的数字，切换为数字输入框，输入权重（1~999）后回车或失焦提交；Esc 取消 |
| 拖拽排序 | hover 行首显示拖拽手柄（⋮⋮），按住拖拽至**同级**其他分类上方/下方完成排序。仅允许同级拖拽，跨层级拖拽无效 |

- 拖拽或编辑完成后，受影响同级分类的排序权重按新顺序自动顺延（1,2,3...）。

### 3.7 预览小程序

原型页面右上角提供【预览】按钮，用于在后台直接预览小程序端 C 端的分类展示效果。

- 点击【预览】按钮，弹出「小程序端预览」弹窗。
- 弹窗内渲染一个手机模拟框，模拟小程序分类页：
  - 顶部状态栏 + 标题（商城名称）+ 胶囊按钮。
  - 搜索框占位。
  - 主体为"左侧一级分类 + 右侧内容区"的经典分类页布局：
    - 左侧列出**所有已开启 C 端展示的一级分类**，点击切换。
    - 右侧顶部展示当前分类 Banner，下方以宫格展示子分类（有子级时）或固定分组（全部/精选/热销/新品等，无子级时）。
  - 底部 Tab 栏（首页 / 分类 / 购物车 / 我的），"分类"高亮。
- 预览仅展示**已开启 C 端展示**的分类；隐藏的分类不出现在预览中。
- 无可见分类时，手机框内展示空状态提示"暂无可见分类，请在后台开启分类的C端展示"。
- 弹窗底部居中提示"仅展示已开启C端展示的分类"，右侧【关闭】按钮关闭弹窗。
- 【预览】按钮上方显示「上次同步时间」。

### 3.8 删除自有营销分类

- 仅可删除**来源为"自有"的营销分类**。
- 点击操作列【删除】，弹出删除确认弹窗：
  - 警告文案：将删除自有分类「XXX」及其 N 个子级分类（有子级时），并自动解除所有商品关联。
  - 提示：删除后不可恢复，关联商品将被解除关联（有子级时为"子级分类将一并删除"）。
  - 【确认删除】/【取消】。
- 确认后即时删除并刷新列表。

### 3.9 平台更新时的合并规则

| 平台变更 | 商城侧处理 |
|---------|-----------|
| 新增分类 | 默认可见，追加至列表末尾 |
| 删除分类 | 标记为已失效，灰色不可操作 |
| 修改名称/图标 | 未修改过则同步；已修改则保留商城侧值 |
| 修改商品关联 | 同步更新，商城侧不可修改 |
| 停用分类 | 商城侧不可访问，操作记录保留 |
| 适用渠道移除本商城 | 分类从导航移除，操作记录保留 |

## 4. 筛选与查询

右侧筛选栏提供以下筛选项，与左侧分类树点击过滤**叠加生效**：

| 筛选项 | 控件 | 说明 |
|--------|------|------|
| 分类名称 | 文本输入 | 模糊匹配分类名称 |
| 分类类型 | 下拉选择 | 全部 / 基础分类 / 营销分类 |
| 来源 | 下拉选择 | 全部 / 平台 / 自有 |
| C端展示状态 | 下拉选择 | 全部 / 显示 / 隐藏 |
| 查询 | 按钮 | 应用筛选条件刷新列表 |
| 重置 | 按钮 | 清空全部筛选条件，恢复全量展示；同时清除左侧分类树选中 |

左侧分类树还提供"全部 / 仅显示"两种树节点筛选切换，控制树中是否展示已隐藏的分类。

## 5. 边界条件与异常处理

| 场景 | 处理规则 |
|------|----------|
| 平台分类被商品中心删除 | 标记为已失效，灰色不可操作 |
| 平台分类被商品中心停用 | 商城侧不可访问，子级同步隐藏 |
| 商品中心发布时商城正在编辑 | 提示"平台数据已更新，请刷新后重新操作" |
| 跨层级拖拽排序 | 拖拽无效，列表顺序不变 |
| 无可见分类时预览 | 手机框展示空状态，引导开启分类 C 端展示 |
| 分类名称重复（平台/自有任意来源） | 阻断保存，红色提示"分类名称「XXX」已存在，请修改"；平台与自有之间、各自内部均不可重名 |

## 6. 视觉与体验规范

- 与商城运营平台前台分类管理保持**一致的视觉风格和交互模式**。
- 平台数据行使用浅灰色背景区分来源，与自有数据形成视觉差异。
- 分类类型标签颜色与运营平台一致：基础分类（蓝）、营销分类（橙）。
- 来源标签：平台（灰）、自有（绿）。
- 预览弹窗以真实手机外观模拟，C 端元素（Banner、宫格、Tab）按小程序视觉还原。
