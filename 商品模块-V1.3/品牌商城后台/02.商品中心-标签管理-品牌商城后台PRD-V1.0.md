## 1. 文档概述

### 1.1 项目背景

商城运营平台（商品中心）集中管理标签分类树、标签值CRUD、颜色配置，标签数据变更后即时同步至品牌商城后台。品牌商城后台需在此基础上查看平台标签、新增商城专属标签、控制平台标签值在本商城 C 端的展示、给本商城商品打标签。

当前品牌商城后台尚无商品标签管理能力，商城工作人员无法创建商城专属标签，也无法控制平台标签在本商城的展示。

### 1.2 项目目标

1. **查看平台标签**：展示商品中心推送的标签数据，标识来源为"平台"。
2. **新增商城专属标签**：创建本商城独有的标签（含标签值和颜色），C端与平台标签合并展示。
3. **控制 C 端展示状态**：通过开关控制标签值在本商城 C 端的展示（平台标签关联关系保留可恢复）。
4. **商品打标签**：给本商城商品关联标签值（平台+商城专属）。

### 1.3 核心术语

| 术语 | 定义 |
|------|------|
| **平台标签** | 商品中心管理的标签，商城侧不可编辑/删除标签本身，仅可控制 C 端展示状态 |
| **商城专属标签** | 商城侧自行创建的标签，来源标记为"自有"，完整CRUD权限 |
| **标签分类** | 标签的归属类别，最多两级。平台分类 + 商城自有分类合并 |
| **标签值** | C端实际展示的文案内容，每个标签值独立绑定颜色 |
| **标签口径** | 标签判定标准说明，仅运营内部参考 |

### 1.4 标签颜色体系

与商品中心保持一致，5种标准颜色：

| 颜色 | 业务语义 | 适用场景 |
|------|----------|----------|
| 营销红 | 强促销/紧迫感 | 限时折扣、清仓、秒杀 |
| 活力橙 | 推荐/热门/新品 | 店长推荐、新品上市 |
| 品质绿 | 信任/服务/保障 | 产地直供、有机认证 |
| 科技蓝 | 属性/参数/中性 | 智能家电、大容量 |
| 极简灰 | 普通描述/弱提示 | 预售、包邮 |

### 1.5 标签值 C 端展示状态（与商品中心一致）

仅控制**C端（小程序端）**展示范围，后台始终展示全部标签值。

| 状态 | C端-商品列表卡片 | C端-商品详情页 | 后台 |
|:----:|:----------:|:--------:|:--:|
| 显示 | 可见（最多2个） | 可见（全部） | 始终可见 |
| 隐藏 | 不可见 | 可见（全部） | 始终可见 |

### 1.6 与商城运营平台的职责边界

| 维度 | 商城运营平台（商品中心） | 品牌商城后台 |
|------|----------------------|------------|
| 标签CRUD | 管理标签分类树、标签值CRUD、颜色配置 | 平台标签不可编辑/删除；仅可新增商城专属标签 |
| 标签值C端状态 | 控制C端全局展示 | 可控制平台/自有标签在本商城 C 端的展示状态，关联保留 |
| 标签值关联 | 统一管理标签值与商品的关联 | 平台关联不可移除；可给本商城商品打标签 |
| 颜色体系 | 定义5种标准颜色 | 使用相同颜色体系 |
| C端展示 | 列表页最多2个、详情页全部 | 规则一致，数据为平台+自有并集 |

## 2. 功能架构

### 2.1 导航与布局

- **导航**：在系统左侧导航栏设置【商品标签管理】二级菜单。
- **整体布局**：采用**单列表格布局**（无左侧分类树）。

页面从上到下分为以下区域：

| 区域 | 说明 |
|------|------|
| 顶部筛选栏 | 标签名称/标签值模糊搜索、来源筛选、C端状态筛选 + 查询/重置按钮 |
| 工具栏 | 左侧【新增商城专属标签】主按钮；右侧统计"共 N 条" |
| 主体 | 标签数据列表，以标签为行粒度 |

> 说明：原型早期版本设计有左侧标签分类树，当前已移除，改为单列筛选+表格布局，简化操作路径。

### 2.2 RBAC权限配置

**按钮级权限**

| 按钮/操作 | mall_admin | mall_operator | mall_viewer | 备注 |
|-----------|:----------:|:-------------:|:-----------:|------|
| 新增商城专属标签 | ✓ | ✓ | — | — |
| 编辑商城专属标签 | ✓ | ✓ | — | — |
| 控制平台标签C端展示 | ✓ | ✓ | — | 关联保留可恢复 |
| 删除商城专属标签 | ✓ | — | — | 需校验关联商品数 |
| 给商品打标签 | ✓ | ✓ | — | — |

## 3. 核心功能说明

### 3.1 标签列表

**列表字段**

| 列 | 说明 |
|----|------|
| 标签ID | 标签唯一标识编码（如 B1001、M2001）|
| 标签名称 | 标签标识名称 |
| 标签值 | 以"色块+文案"Tag形式展示，每个标签值绑定颜色 |
| 来源 | `平台`（灰）/ `自有`（绿） |
| 关联商品数 | 已关联该标签值的本商城商品总数，蓝色数字 |
| 标签口径 | 标签判定标准，文案超长截断，hover 展示完整内容 |
| C端状态 | 开关控件。平台标签：显示/隐藏；商城专属标签：显示/隐藏 |
| 更新人/时间 | 审计信息 |
| 操作 | 平台标签：【详情】；商城专属标签：【编辑】【删除】 |

### 3.2 查看平台标签

- 平台标签数据由商品中心推送，即时同步。
- **不可编辑/删除平台标签本身**：操作列仅有【详情】按钮。
- 点击【详情】打开平台标签详情弹窗，展示标签全部信息（标签ID、名称、分类、标签值、来源、关联商品数、标签口径），均为只读；仅可修改 **C 端展示状态**开关并保存。

### 3.3 新增商城专属标签

- 点击工具栏【新增商城专属标签】，弹出新建弹窗。
- 弹窗顶部提示"新增的标签为商城专属，仅在本商城生效"。
- 字段：

| 字段 | 控件 | 必填 | 说明 |
|------|------|:----:|------|
| 标签名称 | 文本输入 | 是 | 标签标识名称，如"企业定制" |
| 标签分类 | 下拉选择器 | 是 | 列出全部叶子节点分类路径 |
| 标签值 | 动态Tag输入+颜色选择 | 是 | 每个标签值独立选择颜色（5选1，默认营销红），支持"+ 添加标签值"与逐个删除 |
| 标签口径 | 多行文本域 | 否 | 判定标准说明 |
| C端展示状态 | 开关 | — | 默认开启（显示）；提示"仅控制C端小程序展示，后台始终可见全部标签值" |

- 标签值文案唯一性：同一标签下不允许文案完全相同的两个标签值。
- **标签值查重规则**：
- **标签值查重规则**：
  - **标签值全局唯一**：平台标签值之间、商城专属标签值之间、平台与商城专属之间，均**不允许文案重复**（全量标签范围；忽略大小写、去首尾空格后比对）。
  - 保存时校验，命中重复时弹窗内红色提示"标签值「XXX」与「XXX」标签下的值重复（全局唯一），请修改"，并**阻断保存**。

### 3.4 控制标签 C 端展示状态

- 商城可通过列表的 C 端状态开关或平台标签详情弹窗，切换任一标签（平台/自有）在本商城 C 端的展示。
- **C端效果**：
  - 隐藏的标签值：列表卡片不展示（被过滤），详情页仍展示。
  - 后台始终展示全部标签值。
- **关联关系保留**：恢复显示后标签值自动恢复展示。
- 切换即时生效，无需手动同步。

### 3.5 编辑商城专属标签

- 仅可编辑来源为"自有"的标签：标签名称、标签分类、标签值文案/颜色、标签口径、C端展示状态。
- 复用新增弹窗（标题改为"编辑商城专属标签"），编辑即时生效。
- 编辑时同样执行**标签值查重规则**（与全量标签值比对，自身原值不参与查重）。

### 3.6 删除商城专属标签

- 仅可删除来源为"自有"的标签。
- 点击【删除】，二次确认"确认删除标签「XXX」？删除后将自动解除所有关联且不可恢复。"
- 确认后即时删除并刷新列表统计。

### 3.7 商品打标签

- 商品列表/商品详情页提供标签选择器，数据源为平台标签+商城专属标签的并集。
- 平台标签值的关联关系不可在商城侧移除。

### 3.8 标签数据合并规则

- C端标签数据为平台标签与商城专属标签的**并集**，合并展示，不区分来源。
- 因新建/编辑时已阻断重复标签值，C端原则上不会出现重复的标签值文案。
- 标签数据变更即时生效推送至C端，无需手动同步。

## 4. 筛选与查询

顶部筛选栏提供以下筛选项：

| 筛选项 | 控件 | 说明 |
|--------|------|------|
| 标签名称 / 标签值 | 文本输入 | 模糊匹配标签名称或标签值文案 |
| 来源 | 下拉选择 | 全部来源 / 平台 / 自有 |
| C端状态 | 下拉选择 | 全部状态 / 显示 / 隐藏 |
| 查询 | 按钮 | 应用筛选条件刷新列表 |
| 重置 | 按钮 | 清空筛选条件 |

---

## 5. 边界条件与异常处理

| 场景 | 处理规则 |
|------|----------|
| 平台标签被商品中心删除 | 商城侧同步移除，C 端状态记录随之清理 |
| 标签值重复（平台/自有任意来源） | 阻断保存，红色提示重复项及归属标签；平台与自有之间、各自内部均不可重名 |
| 历史数据兼容 | 旧标签无颜色值时默认极简灰 |
| 标签值文案超长 | 超过限制截断加省略号，hover Tooltip展示完整内容 |

---

## 6. 视觉与体验规范

- 与商城运营平台商品标签管理保持**一致的视觉风格和交互模式**。
- 来源标签视觉区分：平台（灰）、自有（绿）。
- 标签值以"色块+文案"形式展示，颜色渲染规则与商城运营平台一致（5色体系）。
- 操作列根据来源显示不同操作按钮：平台仅【详情】，自有为【编辑】【删除】。
