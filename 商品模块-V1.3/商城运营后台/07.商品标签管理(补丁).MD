| 字段 | 内容 |
|------|------|
| 文档名称 | 商品标签管理 - 产品需求文档（PRD） |
| 当前版本 | v2.1 |

## 1. 文档概述

### 1.1 项目背景
当前商品标签虽有基础管理功能，但存在两个核心问题：
1. **视觉规范缺失**：标签没有统一的颜色体系，前端展示风格混乱，无法通过颜色区分"促销"与"属性"等不同业务语义。
2. **应用场景未定义**：运营配置了标签，但前端不清楚在列表页还是详情页展示、展示几个、按什么优先级排序。

### 1.2 项目目标
1. **建立颜色体系**：定义5种标准颜色及其业务语义，运营配置标签时选择对应颜色，前端统一渲染。
2. **明确展示规则**：定义标签在列表页和详情页的展示数量、优先级、截断规则。
3. **完善管理功能**：支持标签分类树管理，提升运营效率。

### 1.3 核心术语

| 术语 | 定义 |
|------|------|
| **标签分类** | 标签的归属类别，最多两级：一级分类（仅目录，不可关联标签）→ 二级分类（叶子节点，可关联标签） |
| **标签** | 标签的标识名称（如"性价比标签"），一个标签下可配置多个标签值 |
| **标签值** | C端实际展示的文案内容（如"高性价比"）。**每个标签值独立绑定一个颜色值**，商品打标时关联到具体标签值，前端展示标签值文字 + 对应颜色 |
| **标签口径** | 标签的判定标准说明（如"价格低于同类目均价20%"），仅运营内部参考，前端不展示 |

**标签值状态**：仅控制**C端（小程序端）**展示范围，对运营平台后台和品牌商城后台**无任何影响**——后台所有页面（标签管理列表、商品详情编辑页、渠道商品管理等）始终展示全部标签值，不受状态限制。

状态变更即时生效。

| 状态 | C端-商品列表卡片 | C端-商品详情页 | 后台（运营平台/品牌商城） |
|:----:|:----------:|:--------:|:------------------:|
| 显示 | 可见（最多2个） | 可见（全部） | 始终可见，不受影响 |
| 隐藏 | 不可见 | 可见（全部） | 始终可见，不受影响 |

**删除行为**：详见 3.2 删除逻辑，此处仅概述：
- 删除标签值 → 自动解除该标签值与所有商品的关联，不可恢复
- 删除标签值后若所属标签下无剩余标签值 → 该标签一并删除
- 删除标签 → 其下所有标签值一并删除，关联全部解除

### 1.4 标签颜色体系

| 颜色 | 业务语义 | 适用场景 |
|------|----------|----------|
| 营销红 | 强促销/紧迫感 | 限时折扣、清仓、秒杀 |
| 活力橙 | 推荐/热门/新品 | 店长推荐、新品上市 |
| 品质绿 | 信任/服务/保障 | 产地直供、有机认证 |
| 科技蓝 | 属性/参数/中性 | 智能家电、大容量 |
| 极简灰 | 普通描述/弱提示 | 预售、包邮 |

- 每个标签值独立选择颜色，5选1，默认为**极简灰**。同一标签下的不同标签值可设置不同颜色。
- 前端渲染规则：营销红 → 红色实心底 + 白字；其余四色 → 描边 + 对应色字。
- 列表页截取优先级：营销红 > 活力橙 > 品质绿 > 科技蓝 > 极简灰（详见 3.4）。

## 2. 功能架构

### 2.1 三端架构与数据流

```
┌─────────────────────────────────────────────────────────────────┐
│                     商场运营平台（商品中心）                        │
│                                                                 │
│  可操作：                                                        │
│  · 管理标签分类树（两级）                                        │
│  · 新增/编辑/删除标签（含颜色配置）                               │
│  · 给商品打标签（渠道商品管理 / 商品详情编辑页）                    │
│                                                                 │
│  展示内容：                                                       │
│  · 标签列表（含关联商品数统计）                                   │
│  · 标签分类树                                                    │
└──────────────────────┬──────────────────────────────────────────┘
                       │  标签数据同步
                       ▼
┌─────────────────────────────────────────────────────────────────┐
│                     品牌商城后台（各商城独立）                      │
│                                                                 │
│  可操作：                                                        │
│  · 查看商品中心推送的基线标签                                     │
│  · 在基线之上新增商城专属标签                                     │
│  · 给本商城商品打标签                                             │
│  · 隐藏基线标签值：在该商城全域隐藏该标签值定义，所有关联该标签值   │
│    的商品均不再渲染此标签值，但关联关系保留，后续可恢复显示         │
│                                                                 │
│  不可操作：                                                       │
│  · 不可编辑/删除基线标签本身                                       │
│  · 不可移除基线标签值关联（基线数据的关联关系由商品中心统一管理）    │
└─────────────────────────────────────────────────────────────────┘
                       │  标签数据合并
                       ▼
┌─────────────────────────────────────────────────────────────────┐
│                     小程序端（C端用户）                            │
│                                                                 │
│  展示内容：                                                       │
│  · 商品列表页：最多2个"显示"标签（按颜色优先级截取）              │
│  · 商品详情页：全部"显示"和"隐藏"标签                             │
│                                                                 │
│  标签来源：运营平台基线 + 品牌商城后台新增，合并展示               │
└─────────────────────────────────────────────────────────────────┘
```

- 品牌商城后台可在此基础上新增商城专属标签，但不可编辑/删除基线标签。
- C端商品标签为基线标签与商城专属标签的并集，合并展示，不区分来源。
- 标签数据变更（新增/编辑/删除标签及标签值、颜色、状态、分类树）即时生效，操作保存后直接推送至品牌商城后台。

### 2.3 导航与布局

- **导航**：在系统左侧导航栏设置【商品标签管理】二级菜单，与"前台分类管理"、"选品清单管理"等核心模块平级。菜单可见性由RBAC权限点控制（详见 2.4）。
- **整体布局**：采用"左侧标签分类树 + 右侧数据表格"布局。
  - 左侧：两级标签分类树，点击一级节点（目录）右侧汇总展示其下所有二级分类的标签值，点击二级节点（叶子）仅展示该分类下的标签值，顶部提供"全部"选项。
  - 右侧顶部：筛选区（标签名称/标签值模糊搜索、更新时间范围、状态筛选）+ 操作栏（【新增标签】按钮）。
  - 右侧主体：标签数据列表。

| 编辑标签 | ✓ | ✓ | ✓ | — | — |

## 3. 核心功能说明

### 3.1 标签分类树管理

- 标签分类树最多**两级**：一级分类 → 二级分类。一级分类仅作为归类目录，**不可关联标签**；仅二级分类（叶子节点）可关联标签。
- 点击一级分类节点时，右侧列表汇总展示其下所有二级分类的标签值。
- 点击二级分类节点时，右侧列表仅展示该分类下的标签值。
- 运营可新增/编辑/删除分类节点。新增时，在一级分类下可创建二级分类；在二级分类下不可再创建子级（已达最大深度）。

**删除分类节点**：
- **一级分类**：校验其下是否有二级分类，若有则阻止并提示"该分类下有 N 个子分类，请先删除子分类后再删除本分类"。
- **二级分类**：校验该分类下是否有标签定义（含其下所有标签值），若有则阻止并提示"该分类下有 N 个标签，请先迁移或删除标签及标签值后再删除分类"。

**分类迁移**：编辑标签弹窗中修改"标签分类"下拉选择（仅列出二级分类），即可将标签及其所有标签值迁移至目标分类。

- 分类树数据独立于前台分类体系，不关联系统类目。
- 分类树变更即时生效。

### 3.2 标签列表管理页

**页面布局**
- 左侧标签分类树 + 右侧数据表格（布局详见 2.3）。
- 顶部筛选区：【标签名称/标签值】模糊搜索、【更新时间】日期范围、【状态】下拉（全部/显示/隐藏）、【查询】、【重置】。
- 操作栏：【新增标签】按钮。

**列表字段**

列表以**标签值**为行粒度（一个标签值 = 一行）。同一标签下的多个标签值各自独立成行，标签名称和标签分类在同行内展示。

| 列 | 说明 |
|----|------|
| 标签ID | 系统自动生成，标签值级别唯一ID |
| 标签名称 | 标签的标识名称（同标签的多个标签值行展示相同名称） |
| 标签分类 | 标签归属的标签分类路径（如"价格属性 > 性价比"） |
| 标签值 | 标签值文案，以"色块+文案"Tag形式展示，色块颜色为该标签值绑定的颜色 |
| 关联商品数 | 已关联**该标签值**的商品SKU总数（实时统计，同一商品关联同一标签下多个标签值时分别计数） |
| 标签口径 | 标签的判定标准说明，hover展示完整内容 |
| 状态 | 开关控件，控制该标签值在**C端**的展示范围。后台不受限制，始终可见（状态定义详见 1.3，C端效果详见 3.4） |
| 更新人/时间 | 审计信息 |
| 操作 | 【编辑】、【删除】 |

**删除逻辑**（此处为权威定义，其余章节仅引用本段）：

- **删除单个标签值**（行内删除按钮）：若该标签值已被 N 个商品关联（N > 0），点击删除时弹窗提示"该标签值已被 N 个商品使用，删除后将自动解除所有关联且不可恢复"，确认后删除该标签值并解除所有商品关联。若删除后所属标签下无剩余标签值，则该标签也一并删除。
- **删除整个标签**（编辑弹窗内操作，详见 3.3）：在编辑弹窗中可删除标签下的所有标签值。若任一个标签值已被商品关联，弹窗提示"该标签下有标签值已被 N 个商品使用，删除后将自动解除所有关联且不可恢复"，确认后删除该标签及其全部标签值，解除所有关联。

> 删除操作受RBAC控制：仅 admin 和 manager 可执行（详见 2.4）。删除即时生效。

### 3.3 新建/编辑标签弹窗

**表单字段**

| 字段 | 控件 | 必填 | 说明 |
|------|------|:----:|------|
| 业务对象 | 下拉（默认"商品"） | 是 | 预留扩展性，当前仅"商品" |
| 标签名称 | 文本输入 | 是 | 标签的标识名称 |
| 标签分类 | 下拉选择器 | 是 | 数据源来自左侧标签分类树，**仅列出二级分类（叶子节点）**供选择 |
| 标签值 | 动态Tag输入+颜色选择 | 是 | 每输入一个标签值时同时选择其颜色（5选1，默认极简灰）。已添加的标签值展示为"文案+色块"，可单独修改颜色或删除 |
| 标签口径 | 多行文本域 | 否 | 标签判定标准说明，仅运营内部参考 |

**编辑已有标签时的行为**：

| 操作 | 行为 | 生效时机 |
|------|------|:--:|
| 修改标签名称 | 该标签下所有标签值行的标签名称同步更新 | 即时生效 |
| 修改标签分类 | 该标签迁移至新分类下，所有标签值跟随迁移 | 即时生效 |
| 新增标签值 | 在当前标签下新增标签值，可独立设置颜色 | 即时生效 |
| 修改已有标签值文案 | 已关联该标签值的商品在C端展示新文案 | 即时生效 |
| 修改已有标签值颜色 | 已关联该标签值的商品在C端展示新颜色，列表页优先级可能因此变化 | 即时生效 |
| 删除已有标签值 | 同 3.2 删除逻辑——有商品关联时二次确认后解除关联 | 即时生效 |
| 删除整个标签 | 删除弹窗内所有标签值，同 3.2 删除整个标签逻辑 | 即时生效 |

**交互细节**：
- 编辑弹窗打开时，自动回填当前标签的全部字段（标签名称、分类、已有标签值及颜色、标签口径）。
- **标签值文案唯一性**：同一标签下不允许存在文案完全相同的两个标签值（输入时前端校验 + 提交时后端校验，提示"该标签下已存在相同文案的标签值"）。不同标签之间标签值文案可重复。

### 3.4 前端展示规则（C端小程序）

以下规则仅约束**小程序端（C端用户可见）**的标签渲染，不影响运营平台后台和品牌商城后台的任何页面。

**商品列表页（搜索结果/分类页）**

| 规则项 | 说明 |
|--------|------|
| 展示位置 | 商品价格下方或标题下方 |
| 展示数量 | 最多 **2个** |
| 过滤规则 | 仅展示"显示"状态的标签值，"隐藏"的不展示 |
| 优先级排序 | 按标签值绑定颜色排序：营销红 > 活力橙 > 品质绿 > 科技蓝 > 极简灰。同颜色按标签值与该商品关联的时间倒序（最近关联的排前面） |
| 截断规则 | 超过2个直接截断，不显示"更多"入口 |

**商品详情页**

| 规则项 | 说明 |
|--------|------|
| 展示位置 | 价格区域下方或规格选择上方 |
| 展示数量 | 展示**所有**标签（含"显示"和"隐藏"状态） |
| 排列方式 | 单行自动换行 |

### 3.5 渠道商品管理中的批量标签操作

渠道商品管理（04）列表页提供批量加标签和批量去标签功能。两类操作均属**标签关联变更**，即时生效。

**批量加标签**

| 步骤 | 说明 |
|------|------|
| 触发 | 渠道商品管理列表页，勾选一个或多个商品，点击底部批量操作栏【批量加标签】 |
| 弹窗 | 弹出标签值选择器，数据源为本模块全部标签值列表。支持按标签名称/标签值模糊搜索、按标签分类树筛选 |
| 选择 | 运营勾选目标标签值（支持多选），已选标签值以 Tag 形式展示在弹窗底部，可单独移除 |
| 确认 | 点击确认后系统逐商品执行关联 |

**关联规则**：
- 若商品已关联该标签值，则跳过（不重复关联，不计入新增数）。
- 若商品已关联同一标签下的其他标签值，新标签值正常追加（同一商品可关联同一标签下的多个标签值）。
- 确认后弹窗展示结果摘要："成功为 N 个商品添加标签，M 个商品已存在该标签无需添加"（N+M = 勾选商品数 × 勾选标签值数中实际操作的条目数）。

**批量去标签**

| 步骤 | 说明 |
|------|------|
| 触发 | 渠道商品管理列表页，勾选一个或多个商品，点击底部批量操作栏【批量去标签】 |
| 弹窗 | 弹出标签值列表，**仅展示所有选中商品的标签值交集**（即每个标签值在所有选中商品上都存在）。每行显示：标签值文案 + 色块 + 所属标签名称 |
| 选择 | 运营勾选要去除的标签值（支持多选） |
| 确认 | 点击确认后弹窗二次确认："将为 N 个商品去除 M 个标签值关联，确认？" |

**去重规则**：
- 仅展示交集：若某标签值只关联了部分选中商品，则不出现（避免误操作影响未关联该标签值的商品）。
- 交集为空时：弹窗展示空状态提示"所选商品无共同标签，无法批量去标签"，【确认】按钮置灰。
- 确认后弹窗展示结果摘要："成功为 N 个商品去除 M 个标签值关联"。

## 4. 数据对接需求

- 前端（C端小程序）获取商品数据时，同时返回该商品已关联的标签值列表（含标签值文案、颜色值、状态、所属标签名称）。
- **隐藏标签值**：接口正常返回，由C端前端根据状态决定——列表卡片过滤掉，详情页展示。后台接口不受状态影响，始终返回全部关联标签值。
- **标签值被删除**：自动解除该标签值与所有商品的关联，接口不再返回。标签下最后一个标签值被删除时，标签本身不再存在。
- **标签选择器**：渠道商品管理和商品详情编辑页的标签选择器展示全部标签值，操作保存后即时生效。

## 5. 边界条件与异常处理

| 场景 | 处理规则 |
|------|----------|
| 标签值文案超长 | 超过4字时前端截断加省略号（如"超级优惠大..."），hover时Tooltip展示完整文案 |
| 列表空状态 | 标签列表无数据时，展示引导提示"暂无标签，点击新增" |
| 历史数据兼容 | 旧标签无颜色值时，前端默认按"极简灰"渲染 |
| 商品下架/删除 | 商品下架或从渠道移除后，其标签关联关系保留。商品重新上架时，原有标签关联自动恢复。仅当商品从供应链彻底删除时，标签关联才被清理 |
| 批量打标签后颜色被修改覆盖 | 若运营在渠道商品管理中通过批量操作为商品关联了某标签值，随后商品中心修改了该标签值的颜色，C端按新颜色渲染，关联关系不受影响 |
| 品牌商城专属标签与基线标签同名 | 品牌商城后台新增的专属标签值文案可与基线标签值重复，二者独立管理。C端合并展示时可能同时出现两个文案相同的标签值（来源不同），此为正常现象不做去重 |
| 并发编辑 | 同一标签被多个运营同时编辑时，以先提交保存的为准，后提交者保存时提示"该标签已被他人修改，请刷新后重新编辑" |

## 6. 与上下游模块的衔接关系

| 关联模块 | 关系方向 | 关系说明 |
|----------|:------:|----------|
| 品牌商城后台 | 下游 | 商品中心标签数据变更后即时同步至品牌商城后台；商城工作人员可新增商城专属标签、隐藏标签值（关联关系保留可恢复），不可编辑/删除商品中心标签本身，不可移除标签值关联 |
| 渠道商品管理（04） | 下游 | 渠道商品管理页列表中"商品标签(商城)"列展示本模块管理的标签值。底部批量操作栏提供【批量加标签】【批量去标签】入口（04 已预留按钮），操作规则详见本模块 3.5 节 |
| 商品详情编辑页 | 下游 | 商品详情编辑页支持为单个商品打标签，操作即时生效。进入编辑页时，若该商品此前已有标签关联，系统自动带入全部已关联的标签值（含颜色和状态，不受"显示/隐藏"状态限制——隐藏的标签值同样带入并正常展示），运营可在此基础上增减调整 |
| 小程序端 | 下游 | 在商品列表页和详情页按规则渲染标签，合并展示来自运营平台和品牌商城后台的标签 |
