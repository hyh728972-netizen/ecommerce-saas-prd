## 1. 文档概述

### 1.1 项目背景

当前渠道商品管理页面（04）中，点击商品【查看】按钮实际上还是供应商填写的信息，运营无法进行深度商品对比以及渠道内容整合。根据下面需求明确点击"查看"操作应进入商品详情页，展示**商品完整信息、在售渠道分布、历史操作记录**三个TAB。

同时，商城运营平台已建立 SPU→SKU→供应商 的三级商品数据模型（详见00编码方案PRD），同一SPU-SKU下聚合了多个供应商的供货信息与商品内容（主图、参数、图文详情）。运营需要在详情页中对不同供应商的内容进行筛选组合，打造统一的C端商品展示。

### 1.2 项目目标

1. **商品信息聚合**：以商城SPU为主键，完整展示 SPU基本信息 → SKU规格 → 供应商报价与内容 的三级数据。
2. **内容策展**：运营从不同供应商提供的主图/参数/图文详情中，按商城SKU维度独立筛选组合，形成小程序默认展示内容。运营不自建内容，只做筛选。
3. **渠道视图**：集中展示商品在各品牌商城的在售情况，含定价、毛利、可售状态，支持改价和移出操作。
4. **操作追溯**：完整记录商品从创建至今的所有变更，支持按操作类型/操作人/时间筛选。

### 1.3 适用范围

本PRD仅覆盖**渠道商品详情页**，入口为渠道商品管理（04）的【查看】按钮。其他模块（供应链商品池、选品清单管理、待处理选品）的商品详情页是否复用本页面，待后续评估。

### 1.4 核心术语

| 术语 | 说明 |
|------|------|
| **商城SPU** | 商城标准商品单元，聚合同款商品，编码前缀 S（实物）/ X（虚拟） |
| **商城SKU** | SPU下的规格单元，如 `{白,常规}`、`{蓝,常规}` |
| **供应商报价** | 供应链SKU维度的供货数据：供货价、MOQ、库存、交期 |
| **内容源** | 供应商提供的商品素材，含主图、产品参数、图文详情。同一SPU多供应商时，各供应商对商品的**命名/型号**可能不同（如"3M 9001V KN95防护口罩 / 9001V" vs "3M 9001V 防雾霾口罩（耳戴式）/ 9001V-CN"），商品名称与产品型号归属于产品参数源，随参数源切换展示对应供应商的叫法 |
| **内容策展** | 运营从不同供应商的内容中选取组合，形成C端展示 |
| **在售渠道** | 商品已上架的品牌商城实例 |
| **组合/营销买赠SKU** | 编码前缀 C，挂靠主件SPU，由多个子件组成（主件+赠品）。供货价=子件成本汇总，销售价在定价推品确定 |
| **系统类目** | 供应链同步的三级类目树，商品固有属性，只读 |
| **前台分类** | 运营在06模块中配置的C端导航分类，可编辑 |
| **标签值** | 运营在07模块中为商品打上的标签，可编辑，C端展示标签文字+颜色 |

### 1.5 与上下游模块的关系

## 2. 功能架构与交互总览

### 2.1 导航架构

- 入口：渠道商品管理（04）页面，SPU行/SKU行/渠道行的【查看】按钮 → 新开浏览器Tab进入商品详情页。

- 当前版本不纳入左侧导航菜单（仅作为详情页，从列表页进入）。
- 入口代入规则详见 [2.3 入口与SKU代入规则](#23-入口与sku代入规则)。

### 2.2 页面整体布局

```
┌─ TopBar ────────────────────────────────────────────────────┐
│ 选品管理 > 渠道商品管理 > 商品详情     [用户头像]             │
├─────────────────────────────────────────────────────────────┤

│ ← Tab内容区（随Tab切换）                                     │
```

三个Tab分别回答三个核心问题：

| Tab | 核心问题 | 运营可操作 |

| 商品日志 | 谁在什么时候改了什么？ | 只读追溯，支持筛选 |

### 2.3 入口与SKU代入规则

渠道商品管理（04）的表格有两种维度，不同层级点击【查看】代入条件如下：

| 维度 | 入口层级 | 详情页行为 |
|------|---------|-----------|
| **商品维度** | SPU行 [查看] | SKU默认选中**最近上架到渠道**的SKU |
| **商品维度** | SKU次行 [查看] | SKU切换器直接定位到该SKU，供应商表代入该SKU数据 |
| **商品维度** | 渠道次行 [查看] | **同SKU行**，定位到该渠道行所属SKU，代入该SKU数据 |
| **渠道维度** | SPU行 [查看] | 同商品维度SPU行，默认SKU |
| **渠道维度** | SKU次行 [查看] | **同商品维度SKU行**，定位到该SKU，代入该SKU数据 |

> **规则**：所有非SPU行的[查看]入口，统一行为 = **定位对应SKU → 展示该SKU供应商表与内容**。渠道行和SKU行查看体验一致。

```
│                   │ ──────────→    │ ● {蓝,常规}         │
```

## 3. 核心功能说明

### 3.1 Tab1 — 商品基础信息

#### 3.1.1 整体结构

页面从上到下分为四个区域。**① SPU头部固定不变，切换SKU仅影响 ③④**：

```
┌─ ① SPU头部（固定，不随下方SKU切换变化）─────────────────────┐
│  左: SPU主图（展示当前SPU主图源选中的图片）                    │
│  右: SPU基本信息 — 供应链信息(只读) + 商城配置(可编辑)        │
├─ ② SKU切换器（单选按钮组）─────────────────────────────────┤
│  ○ S001A00001001 {白,常规}   ● S001A00001002 {蓝,常规}       │
├─ ③ SKU信息 + 供应商表（随②切换变化 ✓）────────────────────  │
│  SKU编码 + 规格 + 关联供应链SKU + SKU主图(checkbox)           │
├─ SPU级内容源选择 ──────────────────────────────────────────── │
│  SPU主图源: [自动/锁定] | 产品参数源: [下拉] | 图文详情源: [下拉] │
├─ ④ 商品详情预览 ───────────────────────────────────────────  │
│  产品参数 + 图文详情（未选择时回退主供内容）                   │
└─────────────────────────────────────────────────────────────┘
```

| 区域 | 随②SKU切换 | 说明 |
|------|:--:|------|
| ① SPU头部 | ✗ 大部分固定 | SPU级信息+主图展示保持不变；但"商品名称/产品型号"归属产品参数源，随参数源切换（未指定时跟随当前SKU主供叫法） |
| ② SKU切换器 | — | 单选按钮组，控制下方③ |
| ③ SKU+供应商表 | ✓ 联动 | 切换SKU → 更新为该SKU的供应商数据+SKU主图checkbox |
| SPU级内容源 | ✗ 固定 | SPU主图源/产品参数源/图文详情源，SPU级统一管理 |
| ④ 商品详情预览 | ✓ 联动 | 跟随②切换+SPU内容源选择，未选择时回退主供内容 |

**SPU头部主图来源逻辑**：
- 默认「自动」：取**最近上架到渠道的SKU**所选中的供应商主图
- 可下拉切换为「锁定」：选择一个SKU → SPU头部主图锁定为该SKU的当前主图，不随任何切换变化
- 锁定时，下方②SKU切换、③供应商表内容源变更均不影响SPU头部主图
- **回退链**（与SKU切换器保持一致）：最近上架SKU → 创建时间最新SKU → 任一个有主图源的SKU → 空状态占位图
- 若所有SKU均未选择主图源 → 展示空状态占位图

#### 3.1.2 ① SPU头部信息区（固定）

左栏 — SPU主图展示：

- 展示SPU级主图（大图预览），来源由SPU级内容源栏的"SPU主图源"下拉控制
- 下方标注当前来源信息
- SPU主图源选择器位于SPU级内容源栏中，与产品参数源、图文详情源并列

**SPU主图来源切换规则**：

| 模式 | 行为 | 场景 |
|------|------|------|
| **自动**（默认） | 自动取最近上架到渠道的SKU的主图（优先取该SKU勾选的，否则取主供的） | 日常使用 |
| **锁定为SKU {X}** | 主图锁定为该SKU的当前主图 | 运营选定代表图 |

右栏 — SPU基本信息，分为两个子区：

```
── 供应链信息（只读）──
  商品名称       3M 9001V KN95口罩          ← 跟随"产品参数源"动态展示
  产品型号       9001V                      ← 跟随"产品参数源"动态展示
  商城SPU        S001A00001
  关联供应链SPU   ZD-A00001, ZD-A00002 (共2个)
  所属品牌       3M
  系统类目       劳保用品 > 防护口罩 > KN95口罩
  商品类型       实物商品
  商城创建时间    2026-03-15 08:00
  供应链创建时间  2026-02-20 14:30

── 商城配置（可编辑）──
  前台分类       医疗用品 > 日常防护 [修改]
  标签           [红]限时特价 ×  [绿]正品认证 ×  [+ 添加标签]
```

> **商品名称/产品型号动态展示**：因同一SPU多供应商时命名规则不同（一品多商），商品名称与产品型号归属于"产品参数源"。切换 SPU 级内容源栏的"产品参数源"下拉时，此两字段同步展示对应供应商的叫法；未指定参数源时回退主供供应商的叫法（与预览区"卖哪个展示哪个"一致）。详见 3.1.5 内容源回退规则。

**供应链信息字段定义**：

| 字段 | 来源 | 说明 |
|------|------|------|
| 商品名称 | 跟随产品参数源 | 展示当前参数源供应商对该商品的命名；未指定参数源时回退主供供应商叫法。各供应商命名可能不同 |
| 产品型号 | 跟随产品参数源 | 展示当前参数源供应商填写的产品型号；未指定参数源时回退主供供应商型号。如供应商A填 `9001V`，供应商D填 `9001V-CN` |
| 商城SPU | 商城编码方案生成 | S=实物 / X=虚拟。若尚未生成 → 显示"待生成"（灰色） |
| 关联供应链SPU | 供应链同款组映射 | 该商城SPU聚合了哪些供应链SPU，hover展开完整列表 |
| 所属品牌 | 供应链商品池同步 | 品牌归属 |
| 系统类目 | 供应链标准类目 | 三级完整路径，商品固有属性，不可编辑 |
| 商品类型 | 编码前缀决定 | 实物商品 / 虚拟商品 |
| 商城创建时间 | 系统生成 | SPU首次创建时间，格式 YYYY-MM-DD HH:mm |
| 供应链创建时间 | 供应链商品池同步 | 该SPU关联的最早供应链SKU创建时间 |

**商城配置字段定义**：

| 字段 | 来源 | 编辑方式 | 说明 |
|------|------|---------|------|
| 前台分类 | 06前台分类管理 | 点击[修改]弹出分类选择器 | 展示**已发布**的基础分类树，**多选checkbox**；商品-分类关联变更即时生效，不走草稿/发布流程（仅分类树结构调整需发布） |
| 标签 | 07商品标签管理 | 点击[+添加标签]弹出标签值选择器 | 三级联动（分类→标签→标签值），已关联标签带×可移除；标签关联变更即时生效 |

> **前台分类与07标签管理逻辑一致**："分类长什么样"（分类树结构调整）走06草稿/发布；"商品属于哪个分类"（商品-分类关联）在详情页即时生效。

**视觉区分**：
- 供应链信息区：左侧淡灰竖线（`border-left: 2px solid #e6e4e0`），字段值颜色略深
- 商城配置区：左侧淡蓝竖线（`border-left: 2px solid #d4e0fc`），可编辑字段有悬停态
- 两区间用浅色分割线分隔



#### 3.1.3 ② SKU切换器

- 位置：SPU头部下方，供应商表上方
- 控件：**单选按钮组（Radio Group）**，平铺展示该SPU下所有SKU，每个SKU一个按钮
- 格式：`○ SKU编码 品牌 商品名 规格`，选中态 `● SKU编码 品牌 商品名 规格`
- 组合/营销SKU同样展示在切换器中，格式含营销标识如 `3M 工业防护专业套装 营销买赠A`
- 默认选中：**最近上架到渠道的那个SKU**（取所有渠道中上架时间最晚的SKU；若多个SKU同日上架，取创建时间最早的）
- 若无任何上架记录 → 取创建时间最新的SKU
- 仅一个SKU时仍显示（保持布局稳定）
- 回退链：最近上架SKU → 创建时间最新SKU → 唯一的SKU

```
SKU切换:  ○ S001A00001001 {白,常规}   ● S001A00001002 {蓝,常规}
```

- **切换行为**：仅影响 ③ SKU供应商表 和 ④ 商品详情预览。① SPU头部除"商品名称/产品型号"外保持不变
  - 商品名称/产品型号归属产品参数源：若已指定参数源 → 不随SKU切换（SPU级共享）；若未指定（自动模式）→ 跟随当前SKU主供的叫法变化
- 切换后该SKU的内容源选择状态（主图/参数/详情checkbox勾选）保持该SKU已有的配置


#### 3.1.4 ③ SKU供应商表

当前选中SKU下的所有供应商对比，是运营的核心决策工作台。

**SKU信息行**（供应商表上方）：

```
商城SKU: S001A00001001 | 规格: {白,常规}
关联供应链SKU: HZ-A00001-001-DF-A001, HZ-A00001-001-DF-D001 (共2个)
已加入选品清单: 2024-Q2-航司积分选品, 618大促-精选爆品  [+ 加入清单]
```

| 字段 | 说明 |
|------|------|
| 商城SKU编码 | 商城编码方案生成。若尚未生成 → 显示"待生成"（灰色） |
| 规格 | 规格值，如 `{白,常规}` |
| 关联供应链SKU | 该商城SKU聚合了哪些供应链SKU，多个时hover展开完整列表 |
| 已加入选品清单 | 展示该SKU当前已加入的选品清单列表，点击清单名可跳转 |

| 操作 | 触发行为 | 说明 |
|------|----------|------|
| **改价** | 跳转改价申请流程 → 提交OA审批。**商城价和渠道价均通过改价申请修改**（直销模式下渠道价=供货价不可单独修改，分销模式下两者均可独立申请） | operator+ |
| **移出** | 弹出二次确认弹窗 | 展示商品名/SKU/目标商城 + 警告"移出操作不可逆" |

**改价流程（OA审批）**：

```
运营点击[改价]
  │
  ├─ 跳转改价申请页面，填写新价格后提交
  │
  ├─ 提交OA审批：
  │     - 该渠道商品自动设为"不可售"状态
  │     - 详情页该渠道行可售状态显示"不可售·审批中"，Toggle置灰+hover提示"改价审批中"
  │     - 商品日志记录"改价申请"
  │     - 审批管理后期规划独立审批管理页面，当前暂不在待处理选品中记录
  │
  ├─ OA审批通过：
  │     - 商品自动恢复"可售"状态
  │     - 渠道售价更新为审批通过的价格
  │     - Toggle恢复可操作
  │     - 商品日志记录"改价"（变更: ¥xx → ¥yy | 操作方式: 审批通过）
  │
  └─ OA审批驳回：
        - 商品自动恢复"可售"状态
        - 渠道售价保持原价不变
        - Toggle恢复可操作
        - 商品日志记录"改价"（操作方式: 审批驳回 | 驳回原因: xxx）
```

**改价与供货模式切换OA并发的处理**：
- 同一商品同一渠道，若改价审批和供货模式审批同时进行 → 各自独立流转
- 两个审批均为通过后才全部生效；任一驳回则该路操作回退

**移出弹窗内容**：
- 商品信息确认行：商品名 + SKU + 目标商城
- 警告文案："移出操作不可逆，若需重新上架需从选品清单重新走定价推品流程"
- 底部按钮：[确认移出]（红色）[取消]
- 确认后该渠道行从列表中移除，Toast提示"已从{渠道名}移出"

**移出边界规则**（与04渠道商品管理PRD 3.5一致）：
- 商品存在进行中/待处理订单或售后时，可正常执行移出，现有订单继续履约
- 仅影响当前渠道，不影响其他商城
- 移出后不可逆，需重新走定价推品流程方可再次上架

## 4. 数据联动规则

### 4.1 SKU切换联动

```
切换SKU（②SKU单选按钮组）
  ├─ ① SPU头部信息（供应链+商城配置）→ 大部分保持不变 ✗
  │     └─ 商品名称/产品型号 → 归属产品参数源：已指定参数源时不随SKU切换（SPU级共享）✗；未指定时跟随当前SKU主供叫法 ✓
  ├─ ① SPU主图 → 取决于主图来源设置：
  │     ├─ 自动模式 → 不跟随②切换，仍展示自动选定的SKU主图 ✗
  │     └─ 锁定模式 → 不跟随②切换，始终展示锁定SKU的主图 ✗
  ├─ SPU级内容源 → 保持不变 ✗（SPU级，所有SKU共享）
  ├─ ② SKU切换器 → 更新选中值 ✓
  ├─ ③ 供应商表 → 切换至新SKU的供应商列表 + SKU主图勾选状态 ✓
  └─ ④ 商品详情预览 → 跟随②切换 ✓
```

### 4.2 内容源变更联动

**SKU级 — SKU主图**：
```
勾选供应商X的"SKU主图"checkbox
  ├─ 取消该SKU下其他供应商的"SKU主图"勾选
  ├─ 若该SKU恰为SPU头部主图来源SKU → ①SPU头部主图同步更新
  └─ 商品日志 → 记录"内容源切换"
```

**SPU级 — 产品参数/图文详情**：
```
SPU级内容源下拉切换
  ├─ 产品参数源变更 → ①SPU头部"商品名称/产品型号"同步切换为该供应商叫法 ✓
  │                  └─ ④预览区参数表首两行（商品名称/型号）同步切换 ✓
  ├─ 图文详情源变更 → ④预览区详情立即切换
  └─ 商品日志 → 记录"内容源切换"
```

### 4.3 供货模式变更联动

**最低价优先 → 供应商指定**：
```
选择供应商 → 确认为最便宜 → 直接切换，主供列显示 ★ 指定
           → 确认为非最便宜 → OA审批
                ├─ 审批通过 → ★ 指定生效
                └─ 审批驳回 → 保持最低价优先
```
**供应商指定 → 最低价优先**：
```
点击[最低价优先] → 二次确认弹窗 → 确认后恢复最低价优先
```

> 两种模式下，不改动渠道已有的定价数据（渠道价/商城价不变），仅提示运营关注。

### 4.4 跨Tab操作联动

| 触发操作 | 影响Tab |
|---------|---------|
| SKU主图变更（Tab1） | Tab3：记录操作日志 |
| SPU内容源变更（Tab1） | Tab3：记录操作日志 |
| 供货模式切换（Tab1） | Tab2：若主供变化→供货价列提示；Tab3：记录操作日志 |
| 主供变更（Tab1，手动或自动） | Tab2：供货价列提示；Tab3：记录操作日志 |
| SPU主图锁定/解锁（Tab1） | Tab3：记录操作日志 |
| 可售切换（Tab2） | Tab3：记录操作日志 |
| 移出（Tab2） | Tab2：渠道行移除；Tab3：记录操作日志 |
| 改价（Tab2） | Tab3：记录操作日志 |
| 前台分类修改（Tab1） | Tab3：记录操作日志 |
| 标签变更（Tab1） | Tab3：记录操作日志 |
| 选品清单变更（Tab1） | Tab3：记录操作日志 |

## 5. 边界条件与异常处理

| 场景 | 处理方式 |
|------|----------|
| SPU下仅1个SKU | SKU切换器仍显示但下拉仅1项（不隐藏，保持布局稳定） |
| SKU下仅1个供应商 | 该供应商自动为主供，内容源默认全部选中，radio和checkbox仍显示但不可取消 |
| SKU下无供应商 | 供应商表显示空状态："该SKU暂无供应商报价数据"；头部主图/参数/详情均为空状态 |
| 某供应商未提供主图 | "SKU主图"列显示"—"，checkbox置灰不可选，[预览]置灰 |
| 某供应商未提供参数 | "产品参数"列显示"—"，checkbox置灰不可选，[预览]置灰 |
| 某供应商未提供详情 | "图文详情"列显示"—"，checkbox置灰不可选，[预览]置灰 |
| 所有供应商均未提供某内容 | 对应维度checkbox全置灰，下方展示区显示空状态："暂无供应商提供产品参数/图文详情" |
| 筛选结果为空（Tab2） | 展示空状态："暂无符合条件的在售渠道" |
| 日志记录为空（Tab3） | 展示空状态："暂无操作记录" |
| 筛选结果为空（Tab3） | 展示空状态："暂无符合条件的操作记录" |
| 网络中断导致操作失败 | Toast提示错误信息，数据回滚至操作前状态 |
| 多人同时切换主供/内容源 | 以最后一次操作为准，不做并发锁（冲突概率低） |
| OA审批中重复提交 | 按钮置灰，hover提示"OA审批中，审批完成后可操作" |
| 供应商（主供）下架/终止 | 自动变为不可售 → 待处理选品 → 模式回退最低价优先 → 主供自动切换 |
| 商品从所有渠道移出 | Tab2角标更新为0，表格展示空状态，Tab1不受影响 |
| SPU下所有SKU均未上架任何渠道 | SKU切换器取创建时间最新；SPU头部主图空状态 |
| 商城SPU/SKU编码尚未生成 | 编码字段显示"待生成"（灰色），hover提示原因。暂以供应链编码（供应链SPU/供应链SKU）作为主标识。不影响其他Tab的功能（在售渠道/商品日志仍可查看） |
