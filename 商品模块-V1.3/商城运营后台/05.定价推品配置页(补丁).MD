**定价推品配置页 - 产品需求文档（PRD）**

| 字段 | 内容 |
|------|------|
| 文档名称 | 定价推品配置页 - 产品需求文档（PRD） |
| 当前版本 | v2.2 |
| 文档性质 | 功能迭代PRD —— 基于现有选品流程，新建定价推品配置页面，解决多渠道、多SKU下的批量定价与利润管控问题 |
| 面向用户 | 商城运营人员、选品专员、渠道管理员 |

---

## 1. 文档概述

### 1.1 项目背景
当前在"选品清单"/"待处理选品中心""渠道商品管理-批量导入（快捷操作）"都可以发起定价推品，需要梳理并优化清晰多线判断规则。

### 1.2 项目目标
优化【定价推品配置页】，作为商品正式上架前的"最后一公里"决策中心。通过可视化的批量计算公式、实时的毛利预览以及清晰的SKU/SPU层级结构，赋能运营人员高效完成从供应链商品到渠道商品的转化，确保价格策略的统一性与合理性。

### 1.3 核心术语
- **定价推品配置页**：商品正式上架至渠道前的定价决策页面，承接选品清单/待处理选品中心/渠道商品管理的商品数据，完成渠道选择与定价策略配置后提交上架。
- **渠道价**：商品在目标渠道的实际售卖价格。统一定价模式下所有渠道共用同一渠道价，*后续设计预留可随供货价波动自动调整*。
- **划线价**：C端小程序展示用的划线原价，实际售卖按渠道价，目的是让顾客感知渠道价更优惠。

## 2. 功能架构与交互总览

### 2.1 导航入口
定价推品配置页非独立菜单页面，由以下三个入口触发进入：

| 入口 | 来源页面 | 触发操作 | 进入模式 |
|------|----------|----------|----------|
| 入口1 | 选品清单详情 | 勾选商品 → 点击【定价推品】→ 前置异常校验通过 → 点击【仅正常商品进入定价】 | 正常模式 |
| 入口2 | 待处理选品中心 | 利润预警异常 → 点击【强制上架】 | 异常模式 |
| 入口2a | 待处理选品中心 | 利润预警【修改价格】/ 供应商优化【一键切换最优】/ 成本变动【接受并更新】/ 重复数据【重新提交】 | 正常模式 |
| 入口3 | 渠道商品管理（快捷操作，早期转数字化线下转线上必须） | 导入Excel校验通过 → 点击【仅正常商品进入定价】 | 正常模式 |

### 2.2 整体布局
页面采用上下结构：
- **Step 1**：渠道销售模式（选择直销/分销模式，决定定价计算逻辑与可用渠道范围）。
- **Step 2**：选择上架渠道（根据Step 1的销售模式，展示对应类型的渠道供选择）。
- **Step 3**：定价与配置（核心内容区，包含全局定价控制台与SKU列表），全局控制台采用吸顶设计。
- **底部操作栏**：悬浮固定，含汇总信息与【取消】/【确认定价与进行推品】按钮。

### 2.3 数据流向
- **输入**：选中的SPU/SKU列表、供应链供货价、电商价。
- **处理**：应用定价公式、计算毛利、校验价格合理性（详见 3.5.1 三级校验链路）。
- **输出**：生成渠道商品SKU、写入渠道价、商城价与划线价。点击【确认】完成推品上架至渠道商城，提交成功后跳回来源页。

**核心计算逻辑**：

| 销售模式 | 渠道价定义 | 商城价 | 我司毛利计算 | 渠道毛利计算 |
|----------|-----------|--------|-------------|-------------|
| **直销模式** | 最终商品销售价 | = 渠道价（不可修改） | $$\frac{渠道价 - 供货价}{渠道价} \times 100\%$$ | — |
| **分销模式** | 我司提供给渠道的商品销售价 | 最终商品销售价（可修改，必须 > 渠道价） | $$\frac{渠道价 - 供货价}{渠道价} \times 100\%$$ | $$\frac{商城价 - 渠道价}{商城价} \times 100\%$$ |

**风控红线**：
- **我司毛利**：毛利率 < 10% 时标红提醒。异常模式下此告警不触发。
- **渠道毛利**（仅分销模式）：毛利率不能为负数，即商城价必须 > 渠道价。

### 2.4 与上下游模块的关系

| 关联模块 | 关系说明 |
|----------|----------|
| 选品清单管理 | 上游：勾选商品经前置异常校验后，正常商品进入定价推品配置页正常模式 |
| 待处理选品中心 | 双向：待处理操作（改价/供应商优化等）进入正常模式；强制上架进入异常模式。定价提交时的渠道价≤供货价异常回流至待处理中心 |
| 渠道商品管理 | 双向：Excel批量导入正常商品进入正常模式；定价提交后生成渠道商品记录 |

### 2.5 页面模式说明

| 模式 | 触发条件 | Banner | 校验行为 |
|------|----------|--------|----------|
| **正常模式** | 入口1/入口2a/入口3 | 无 | 三级校验全开（必填 + 渠道价>供货价 + 10%毛利率二次确认） |
| **异常模式** | 入口2（利润预警强制上架） | 黄色Warning常驻横幅 | 跳过全部校验，直接提交上架 |

| 切换渠道销售模式（直销/分销） | ✓ | ✓ | ✓ | — | — |
| 批量设价（勾选+弹窗） | ✓ | ✓ | ✓ | — | — |
| 修改渠道价/商城价/划线价 | ✓ | ✓ | ✓ | — | viewer只读 |

## 3. 核心功能说明

### 3.1 渠道销售模式 (Step 1)

在进入定价配置前，需选定渠道销售模式，决定定价计算逻辑与利润监控维度。

#### 3.1.1 销售模式选择 (Radio Group)

- **直销模式（默认）**：我司直接将商品销售给C端消费者。
    - **渠道价** = 最终商品销售价。
    - **商城价**：自动等于渠道价，**不可修改**（灰色只读态），Tooltip 提示"直销模式下商城价等于渠道价"。
    - **利润计算**：仅计算**我司毛利**，公式为 $$\frac{渠道价 - 供货价}{渠道价} \times 100\%$$。
    - **适用场景**：自营商城、品牌直营等无中间商的场景。

- **分销模式**：我司将商品提供给渠道商，由渠道商进行最终销售。
    - **渠道价** = 我司提供给渠道的商品销售价（我司收入）。
    - **商城价** = 最终商品销售价（C端消费者支付价格），**可修改**，必须 ≥ 渠道价。
    - **利润计算**：同时计算两项毛利：
        - **我司毛利**：$$\frac{渠道价 - 供货价}{渠道价} \times 100\%$$，毛利率 < 10% 时标红提醒。
        - **渠道毛利**：$$\frac{商城价 - 渠道价}{商城价} \times 100\%$$，**不能为负数**（即商城价必须 ≥ 渠道价），为负数时标红提醒并阻止提交。
    - **适用场景**：经销、代销、多级分销等涉及渠道商分润的场景。

#### 3.1.2 模式切换行为

- **直销 → 分销**：商城价解锁可编辑，初始默认值为渠道价（运营需手动调整至最终售价）。
- **分销 → 直销**：商城价自动恢复为渠道价并锁定，清空渠道毛利列数据。
- **模式选择作用于全页面**：所有SKU统一适用当前选定的销售模式，不支持SKU级单独设置。

### 3.2 选择上架渠道 (Step 2)

- **功能描述**：根据 Step 1 选定的销售模式，从对应类型的渠道池中选择目标上架渠道。每个品牌商城渠道在入驻时已确定其销售模式属性（直销/分销），此处仅展示与当前销售模式匹配的渠道。
- **渠道-销售模式映射**：
    - **直销渠道**：政企福利商城、宏兆自营小程序、社区公益点（我司直接面向C端销售）
    - **分销渠道**：航司积分小站、商城会员购（通过渠道商间接销售）
- **交互设计**：
    - **多选下拉框**：仅展示与当前销售模式匹配的渠道，支持搜索渠道名称，每个渠道旁标注其销售模式类型。
    - **已选标签**：选中后展示为Tag，标注渠道类型（直销/分销），支持点击 `x` 移除。
    - **文案提示**："已选 N 个直销/分销渠道，本次将对 N 个渠道执行选品"。
- **逻辑规则**：
    - 至少选择 1 个渠道，移除至 0 时阻止操作并 Toast 提示"请至少保留一个渠道"。
    - **切换销售模式时**：已选渠道自动清空，重新选取新模式下的首个可用渠道。
    - 若渠道 > 1，默认进入"统一定价模式"。
    - **从待处理进入时**：自动预填该待处理记录关联的目标渠道（单选），不可修改。若锁定渠道与当前销售模式不匹配，阻止模式切换。

### 3.3 全局定价控制台 (Step 3)

此区域采用**吸顶设计**，方便用户在滚动长列表时随时调整策略。

#### 3.3.1 定价模式切换 (Radio Group)

- **所有渠道统一定价（默认）**：同一个SKU商品所有渠道共用一个**渠道价**，操作最简便。渠道价后续设计预留可随供货价波动而自动调整。
- **按渠道单独设价**：点击后，下方SKU行展开，每个渠道可单独配置渠道价，适用于不同商城差异化定价场景。
- **模式切换数据迁移**：从统一设价切换至单独设价时，已填的渠道价自动复制到每个渠道的渠道价字段作为初始值；从单独设价切回统一设价时，清空各渠道单独价格，恢复为单一渠道价输入框。

#### 3.3.2 批量设价

通过勾选 SKU + 底部按钮 + 弹窗完成批量定价操作：

- **勾选 SKU**：列表每行前设有复选框，表头提供全选复选框（支持半选态），底部栏实时显示已勾选数量。
- **触发入口**：底部操作栏 `[批量设价]` 按钮（未勾选时置灰不可点击）。
- **弹窗设计**：弹出批量设价计算器弹窗，两行公式并列：
    - `渠道价 = 供货价 × [ N ] (倍率)`，`划线价 = 渠道价 × [ N ] (倍率)`。
    - N 默认为 1，最小值为 1。至少填入一个倍率后确认。
    - 倍率默认记录上次填写的值（localStorage 持久化）。
- **手动修改保护**：若已勾选 SKU 中存在手动修改过的价格，点击确认时弹出二次确认"检测到 N 个SKU已手动修改价格，应用公式将覆盖手动修改，是否继续？"，确认后仅对已勾选 SKU 应用公式，取消则不做变更。

### 3.4 SKU定价列表与风控

这是页面的主体部分，展示具体的商品信息和计算结果。

- **SPU分组头**：展示SPU缩略图、SPU名称、SPU编码。点击箭头展开/收起该SPU下的所有SKU。
- **SKU行详情**（每行首列为复选框，支持勾选后批量设价）：
    - **基础信息**：SKU图片、规格（如"黑色/40码"）、供货价（只读）、电商参考价（只读，灰色小字）。
    - **定价输入**：
        - **渠道价**：支持手动输入，也受顶部批量公式控制。
        - **划线价**：C端小程序展示用（如划线原价），实际售卖按商城价（分销模式）或渠道价（直销模式），目的是让顾客感知售卖价更优惠。默认取电商参考价，若电商参考价 < 商城价 + 1，则自动调整为商城价 + 1。可手动修改。**硬性校验**：划线价必须 ≥ 商城价 + 1 元，输入小于该值时直接限制填入（input 失焦自动回退至商城价+1），并 Tooltip 提示"划线价需大于商城价至少1元"。
    - **我司毛利**：显示"预估毛利"和"我司毛利率"。
        - **正常状态**：我司毛利率 ≥ 10%，文字显示为黑色。页面设计遵循"正常即黑色、异常才红色"原则，便于运营快速扫读定位问题。
        - **告警状态**（仅正常模式触发）：我司毛利率 < 10%，文字变为红色，数字后跟随红色感叹号图标 `⚠`。鼠标悬停时显示 Tooltip："当前毛利率低于10%安全线，建议调整售价"。
        - **异常模式**：不执行10%红线判断，毛利率始终以正常黑色字体展示，无红色告警、无 Tooltip 提示。
    - **商城价**（仅分销模式显示）：最终商品销售价。
        - **分销模式**：**可手动修改**，用于计算渠道毛利。必须 > 渠道价，小于等于渠道价时失焦自动回退至渠道价 + 0.01，并 Tooltip 提示"商城价必须大于渠道价"。位于我司毛利率与渠道毛利之间，便于运营按计算顺序依次操作。
        - **直销模式**：不单独展示（商城价 = 渠道价，已体现在渠道价列）。
    - **渠道毛利**（仅分销模式显示）：显示"渠道预估毛利"和"渠道毛利率"。
        - **正常状态**：渠道毛利率 > 0%，文字显示为黑色。
        - **告警状态**（仅正常模式触发）：渠道毛利率 ≤ 0%（即商城价 ≤ 渠道价），文字变为红色，数字后跟随红色感叹号图标 `⚠`。鼠标悬停时显示 Tooltip："渠道毛利为负，渠道商将亏损，请调整商城价"。
        - **异常模式**：不执行渠道毛利判断，始终以正常黑色字体展示。

**直销模式示例**：

| SKU名称 | 供货价 | 渠道价(输入) | 我司毛利 | 我司毛利率 | 状态 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Nike鞋-黑40 | 389 | 499 | 110 | 22.0% | 正常 |
| Nike鞋-黑41 | 389 | **400** | 11 | **2.75%** | ⚠告警 |

**分销模式示例**：

| SKU名称 | 供货价 | 渠道价(输入) | 我司毛利 | 我司毛利率 | 商城价(输入) | 渠道毛利 | 渠道毛利率 | 状态 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Nike鞋-黑40 | 389 | 420 | 31 | 7.38% | 499 | 79 | 15.83% | ⚠我司毛利低 |
| Nike鞋-黑41 | 389 | 400 | 11 | 2.75% | **380** | **-20** | **-5.26%** | ⚠我司毛利低+渠道亏损 |

### 3.5 底部操作栏

- **悬浮固定**：当页面内容过长时，底部栏固定在视窗底部。
- **左侧汇总**：
    - 显示"已选 N 个渠道 · N 个 SKU"。
    - **风险汇总**：
        - 若存在我司低毛利商品，显示红色文字"包含 N 个我司低毛利商品（<10%）"。
        - 若存在渠道毛利为负商品（仅分销模式），显示红色文字"包含 N 个渠道亏损商品（渠道毛利≤0）"。
        - 异常模式下不显示风险汇总。
- **左侧按钮**：
    - `[批量设价]`：勾选 SKU 后点击，弹出批量设价计算器弹窗（详见 3.3.2），未勾选时置灰不可点击。
- **右侧按钮**：
    - `[取消]`：放弃操作，按入口返回：
        - 选品清单进入 → 返回清单详情页（商品留在清单中不变）。
        - 渠道商品管理导入进入 → 返回导入弹窗。
        - 待处理强制上架进入 → 返回待处理列表（商品状态回滚，待处理记录恢复原状）。
    - `[确认定价并进行推品]`：
        - **正常模式 —— 四级校验链路**：
            1. **必填校验**：所有SKU渠道价是否已填写；分销模式下还需校验商城价是否已填写。未填则拦截并 Toast 提示"请填写所有SKU的渠道价和商城价"，页面自动滚动至首个未填写行。
            2. **价格关系校验**：逐条校验 **渠道价 > 供货价**（划线价已在输入时强制 ≥ 商城价+1，此处不再重复校验）。若有商品不满足，弹出【定价异常校验结果】弹窗（详见 3.5.1）：
                - `[仅正常商品提交]`：正常商品（满足渠道价>供货价）进入下一步校验；异常商品自动转入【待处理选品中心】，问题类型标记为"利润预警"，弹窗关闭。
                - `[返回修改]`：关闭弹窗，返回定价页面继续编辑，不做任何提交。
            3. **渠道毛利校验**（仅分销模式触发）：逐条校验 **商城价 > 渠道价**（即渠道毛利率 > 0%）。若有商品不满足，弹出二次确认框："部分商品渠道毛利为负（商城价 ≤ 渠道价），渠道商将亏损，确认要继续上架吗？" 选项：`[取消]` / `[确认强制上架]`。确认后进入下一步校验。
            4. **10%我司毛利率校验**：通过前三步的商品，若存在我司毛利率 < 10%，弹出二次确认框："部分商品我司毛利率低于10%，确认要上架吗？" 选项：`[取消]` / `[确认强制上架]`。确认后提交上架，跳回来源页。
        - **异常模式**：跳过以上全部校验，直接提交上架，跳回来源页（待处理选品中心）。

#### 3.5.1 定价异常校验结果弹窗（仅正常模式触发）

- **触发条件**：正常模式下点击【确认选品并保存价格】，存在不满足 渠道价 > 供货价 的商品。
- **弹窗结构**：
    - **标题**：定价异常校验结果
    - **顶部摘要**："共 N 个商品，其中 M 个存在价格异常（渠道价 ≤ 供货价），N-M 个可正常上架。"
    - **异常商品列表**（可滚动，默认展开）：每行显示商品名称、SKU、供货价、渠道价、异常原因（"渠道价 ≤ 供货价，预计亏损"）。
    - **底部操作**：
        - `[仅正常商品上架]`：主按钮，正常商品进入10%校验流程，异常商品转入待处理选品中心。
        - `[返回修改]`：次按钮，关闭弹窗返回定价页面继续编辑。
- **转入待处理的数据字段**：商品名称、SKU、供货价、渠道价、目标渠道、异常产生时间、来源类型（"清单推品" / "渠道导入"，按入口来源标记）、问题类型固定为"利润预警"、异常详情文案。

## 4. 异常情况处理

- **价格为空**：若渠道价未填写，毛利栏显示 `-`；分销模式下若商城价未填写，渠道毛利栏显示 `-`。点击提交时拦截并 Toast 提示"请填写所有SKU的渠道价和商城价"，同时页面自动滚动至首个未填写的SKU行。
- **供货价缺失**：若供应链未维护供货价，整行置灰不可编辑，并提示"缺少供货价，无法定价"。
- **商城价违规**（分销模式）：若输入商城价 ≤ 渠道价，input 失焦自动回退至 渠道价 + 0.01，并 Tooltip 提示"商城价必须大于渠道价"。此校验在失焦时即执行，不等到提交。
- **划线价默认值违规**：若电商参考价 < 商城价 + 1，划线价默认值自动调整为商城价 + 1。
- **网络延迟**：批量计算时若接口延迟，输入框应处于Loading状态，防止用户重复点击。
- **取消/中断处理**（异常模式）：若运营人员在定价页面点击返回、取消或直接关闭页面，商品状态回滚至操作前，待处理记录恢复原状（重新出现在待处理列表中，保留原异常类型与详情），不会产生孤儿数据。

## 5. 视觉与体验规范

- **页面标题**：顶部居中或左对齐显示"定价推品配置"，下方面包屑展示来源路径（如"选品清单 > 定价推品配置"）。
- **实时计算反馈**：渠道价输入失焦后即时更新毛利与毛利率，无需额外点击"计算"按钮。
- **吸顶控制台**：全局定价控制台随页面滚动保持吸顶，确保运营在浏览长列表时随时调整策略。
- **即时反馈**：提交成功后 Toast 提示"推品上架成功"，随即跳回来源页；提交失败时错误信息以内联提示或Toast展示。
