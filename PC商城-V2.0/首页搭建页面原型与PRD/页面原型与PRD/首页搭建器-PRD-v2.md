## 1. 产品概述

### 1.1 需求背景

苏银豆积分商城 PC 端当前首页及活动专题页采用"原型 + 静态页面"的方式维护，任何文案、图片、商品、楼层、活动规则的调整都需要前端介入改代码、发版上线，存在以下问题：

- 排期长：从需求提出到上线平均 3–5 个工作日；
- 试错成本高：活动效果不好也来不及调整；
- 楼层/活动多场景难以并行管理；
- 运营无法独立完成日常调整。

为解决上述问题，需要提供一套**面向运营的 PC 端可视化搭建器**，让运营人员通过开关、表单、列表编辑即可完成首页与活动专题页的配置，并导出标准 JSON 配置，由后端读取后渲染上线。

### 1.2 产品目标

| 目标 | 衡量指标 |
|---|---|
| 运营自助完成首页/活动页配置 | 运营独立完成率 ≥ 95%，无需开发排期 |
| 配置即所见 | 预览与线上效果一致（WYSIWYG） |
| 多页面并行管理 | 同时支持 1 个标准首页 + N 个活动子页面 |
| 配置可追溯、可回滚 | 自动保存到本地 + 支持恢复默认 |
| 降低开发成本 | 前端零开发即可上线常规改版 |

### 1.3 目标用户

| 角色 | 主要场景 | 关键诉求 |
|---|---|---|
| 运营人员 | 日常首页调整、活动促销页搭建、商品/图片更换 | 操作直观、所见即所得、不依赖开发 |
| 活动策划 | 大促专题页搭建，含主视觉、规则、楼层 | 多活动页并行、可快速复制 |
| 产品经理 | 原型阶段快速验证页面方案 | 配置实时生效、可预览整体效果 |
| 前端开发 | 仅维护搭建器本身与组件库，不再介入日常配置 | 组件复用、配置 JSON 规范 |
| 后端开发 | 接收 JSON 配置并渲染页面 | 配置结构稳定、向后兼容 |

### 1.4 名词解释

| 术语 | 含义 |
|---|---|
| 标准首页（main） | 商城默认首页，全局唯一，路由 `01.首页-原型页面.html` |
| 活动子页面（sub） | 基于活动模板创建的专题页，可创建多个 |
| 壳层组件（Shell） | 活动页与首页共享的组件：顶部导航栏 / 搜索头部 / 页脚 / 侧边工具条 |
| 内置组件 | 搭建器内置的页面模块（楼层、推荐、页脚等） |
| 风格（Theme） | 页面全局背景、主色、字号等 |
| 自动保存 | 每次改动自动写入浏览器本地存储 |

## 2. 功能架构

### 2.1 整体布局

搭建器采用 **顶栏 + 三栏工作区** 的结构：

```
┌──────────────────────────────────────────────────────────────────┐
│ 顶栏：品牌 / 页面名 / 自动保存提示 / 风格设置 / 预览 / 保存 / 发布 │
├──────────┬─────────────────────────────────┬─────────────────────┤
│  左栏     │         中栏：预览画布           │       右栏          │
│ ┌──────┐ │                                 │                     │
│ │ 页面  │ │   实时渲染当前编辑页面           │   属性面板 /        │
│ │ 列表  │ │   支持 25%~100% 缩放            │   风格面板          │
│ ├──────┤ │                                 │                     │
│ │ 内置  │ │                                 │                     │
│ │ 组件  │ │                                 │                     │
│ │ 列表  │ │                                 │                     │
│ └──────┘ │                                 │                     │
└──────────┴─────────────────────────────────┴─────────────────────┘
```

| 区域 | 主要内容 |
|---|---|
| 顶栏 | 品牌（首页搭建器）、当前页面名与标签、自动保存提示、风格设置、预览、保存、发布 |
| 左栏上 | **页面** 树：列出标准首页与所有活动子页面，支持新增、切换、重命名、创建副本、删除 |
| 左栏下 | **内置组件** 列表：按"页面主体/浮层组件"分组，支持开关、拖拽排序、复制、删除、重命名 |
| 中栏 | 预览画布（缩放 25%–100%），点击组件即选中并自动滚动到属性面板 |
| 右栏 | 属性面板：根据选中组件动态生成配置项；或风格面板（全局主题） |

### 2.2 功能模块总图

```
首页搭建器
├── 页面管理
│   ├── 标准首页（唯一，不可删除）
│   ├── 活动子页面（可创建多个，可重命名/复制/删除）
│   └── 壳层组件跟随首页（topbar/header/footer/sideToolbar）
├── 组件管理
│   ├── 内置组件列表（分组、计数、开关）
│   ├── 全部启用 / 全部隐藏 / 恢复默认
│   ├── 同组内拖拽排序
│   └── 楼层组件：复制 / 重命名 / 上移下移 / 删除（至少保留 1 个）
├── 风格设置（全局主题）
│   ├── 背景模式：纯色 / 背景图
│   ├── 背景色 / 主色 / 默认字色 / 默认字号
│   └── 页面背景图（本地上传 / 素材库）
├── 属性配置
│   ├── 内容/风格/高级 三段折叠
│   ├── 文本 / 数字 / 颜色 / 下拉 / 开关
│   ├── 跳转页面下拉（仅展示页面名，兼容旧语义路由）
│   ├── 列表编辑（增删改、上下移）
│   ├── 图片选择（本地上传 / 素材库 / 清除）
│   └── 商品选择（多选，按 列×行 限制）
├── 预览
│   ├── 实时刷新（修改 < 200ms）
│   ├── 缩放（25%–100%，步长 5%）
│   ├── 选中组件自动居中滚动
│   └── 新窗口预览真实原型页面
└── 保存与发布
    ├── 自动保存到浏览器本地
    ├── 手动保存 → 导出 JSON 配置
    └── 发布 → 确认弹窗 + 配置汇总预览
```

## 3. 顶栏操作区

### 3.1 顶栏信息与操作

| 位置 | 元素 | 说明 |
|---|---|---|
| 左侧 | 品牌名 | "首页搭建器" |
| 左侧 | 分隔符 | — |
| 左侧 | 当前页面名 | 跟随选中页面切换，例如"标准首页" / "新页面 1" |
| 左侧 | 页面标签 | "首页" 或 "活动"；活动页标签样式不同 |
| 右侧 | 自动保存提示 | 默认"已自动保存"；手动保存后变为"已手动保存" |
| 右侧 | 风格设置 | 进入全局主题面板，自动取消选中组件 |
| 右侧 | 预览 | 新标签页打开当前页面对应的线上原型 HTML |
| 右侧 | 保存 | 弹出确认框 → 导出 JSON 配置（在弹窗中展示） |
| 右侧 | 发布 | 弹出确认框 → 展示配置汇总（每个组件的启用状态、关键参数） |

### 3.2 保存/发布交互

- **保存**：弹出确认弹窗（"确定保存「页面名」的配置吗？"）→ 确认后导出 JSON 并展示在模态框中供复制；提示语变为"已手动保存"。
- **发布**：弹出确认弹窗（"确定发布「页面名」吗？"）→ 确认后展示**配置汇总**：
  - 按顺序列出每个组件的中文名 + 类型 + 启用状态；
  - 关键摘要：运营四宫格（各槽位类型）、楼层（布局模式 + 楼层号）、推荐流（列×行 + 频道数）、楼层锚点（锚点数）、侧边工具条（入口数）、壳层（标注"跟随标准首页"）。

## 4. 左栏：页面 + 内置组件

左栏上下分栏，中间分隔条可上下拖动（高度写入本地存储，最少 140px，最多占用左栏一半高度）。

### 4.1 页面列表

- **页面分组**：
  - 主页面：标准首页（路由 `01.首页-原型页面.html`）
  - 子页面：所有活动子页面（默认含 1 个 `02.活动页-原型页面.html`）
- **顶部操作**：「+ 新建」按钮 → 创建一个活动子页面，命名"新页面 N"，使用活动模板默认组件。
- **页面项交互**：
  - 点击 → 切换到该页面进行编辑（自动保存上一个页面状态）
  - 双击名称 → 行内重命名（最长 40 字符，回车保存 / ESC 取消）
  - 「⋮」更多菜单 → 重命名 / 创建副本 / 删除
- **不可删除项**：标准首页不可创建副本、不可删除；删除子页面需二次确认。

### 4.2 内置组件列表

- **分组展示**：按 `页面主体`（page）/ `浮层组件`（float）两组顺序展示。
- **角标计数**：右上角显示「已启用数 / 总数」。
- **批量操作**：
  - 全部启用：把所有非壳层组件置为启用
  - 全部隐藏：把所有非壳层组件置为隐藏
  - 恢复默认：将当前页面组件 + 全局风格重置为模板默认值
- **组件项交互**：
  - 点击 → 选中该组件，右侧属性面板加载其配置，预览区平滑滚动到该组件位置
  - 开关 → 切换启用/隐藏（壳层组件在活动页中不可改，跟随首页）
  - 拖拽手柄（⋮⋮） → 同组内任意位置排序（壳层组件不可拖拽）
  - 双击标题（仅楼层） → 行内重命名
  - 「⋮」更多菜单：
    - 楼层：重命名 / 复制 / 上移 / 下移 / 删除（仅剩 1 个楼层时禁用删除）
    - 非楼层：上移 / 下移（不提供复制和删除）
- **壳层标记**：活动页中的壳层组件展示「首页」徽标 + 禁用开关 + tooltip "跟随标准首页，不可改"。

## 5. 中栏：预览画布

### 5.1 预览工具条

- **左侧**：当前页面名称 + 提示语"预览对齐线上首页 · 商品图为示意"
- **右侧**：缩放控件
  - 「−」「+」按钮：每次步长 5%
  - 拖动条：范围 25%–100%
  - 当前比例显示：默认 50%

### 5.2 预览渲染

- **实时性**：任何属性/列表/风格的修改均在 ≤ 200ms 内重新渲染。
- **缩放**：通过 CSS `transform: scale()` 实现；缩放比例写入 `--pw-zoom` 变量。
- **点击交互**：点击画布内任意组件块 → 选中并平滑滚动到该组件位置。
- **壳层联动**：活动页预览中，壳层组件的展示与开关状态完全跟随当前标准首页的配置（搜索头部除外，强制白底无促销卡）。

### 5.3 「预览」按钮

- 顶栏「预览」按钮在新标签页打开当前页面对应的真实原型 HTML（如 `01.首页-原型页面.html` / `02.活动页-原型页面.html`），用于查看无搭建器外壳的纯线上效果。

## 6. 右栏：属性 / 风格面板

右栏可整体收起（点击侧边「›」按钮），收起后点击侧栏任意位置自动展开。

### 6.1 空状态

未选中组件且未进入风格面板时：
- 显示提示文案："在画布或左侧「内置组件」中选择组件 / 或点击顶栏「风格设置」配置页面背景 / 字体"
- 角标："请选择组件"

### 6.2 配置项类型

| 类型 | 控件 | 适用场景 |
|---|---|---|
| 文本 | `<input type="text">` | 标题、副标题、占位文字、链接 |
| 数字 | `<input type="number">` + 单位 | 高度、宽度、列数、行数、间隔、轮播周期 |
| 颜色 | `<input type="color">` | 背景色、文字色、主色、标签色 |
| 颜色对 | 两个 color（→ 渐变） | 渐变起始/结束色 |
| 下拉 | `<select>` | 布局模式、模块类型、品牌展示形式、跳转页面 |
| 开关 | checkbox + 自定义样式 | 是否展示、是否启用某功能 |
| 列表 | 卡片式列表（增删改 + 上下移） | 公告、热搜词、菜单、商品列表、品牌列表等 |
| 标签列表 | 简化列表 | 商品标签 |
| 图片选择 | 缩略图 + 三个按钮 | 任何 `img/imgKey` 字段 |
| 商品选择 | 弹窗多选 | 楼层 / 推荐流 / 运营四宫格商品 |

### 6.3 配置项分组

组件配置按以下三段折叠展示（默认全部展开，"高级"段标识为 `is-adv`）：

- **内容**（content，蓝色标签）：标题、文案、列表、商品等业务字段
- **风格**（style，紫色标签）：颜色、高度、间距等样式字段
- **高级**（adv，灰色标签）：跳转链接、特殊开关等

### 6.4 图片选择器

每个图片字段都提供三种来源：

| 操作 | 说明 |
|---|---|
| 本地上传 | 选择本地图片文件，FileReader 读取为 dataURL 回填到 `img` 字段，同时清空 `imgKey` |
| 素材库 | 打开素材库弹窗，网格展示 `IMG` 字典内全部素材，选中后回填 `imgKey`，清空 `img` |
| 清除 | 删除当前 `img` 与 `imgKey`，回退到组件默认占位图 |

- 优先级：本地上传 `img` > 素材库 `imgKey` > 默认占位图。
- 仅允许上传图片类型（`file.type.startsWith('image/')`），否则提示"请选择图片文件"。

### 6.5 商品选择器（弹窗）

| 场景 | 触发位置 | 上限 |
|---|---|---|
| 运营四宫格 · 商品宫格槽位 | 槽位属性中的"选择商品" | 列 × 行 |
| 分类楼层 · 商品网格 | 楼层属性中的"选择商品" | productColumns × productRows |
| 商品推荐 · 单个频道 | 频道属性中的"选择商品" | columns × rows |

- 弹窗内网格展示商品池（含品牌、名称、价格、缩略图）；
- 多选，超出上限时 alert 拦截："最多选择 N 个商品（与列数×行数一致）"；
- 底部计数："已选 X / N"；
- 确认后写入对应字段；取消则关闭弹窗不做变更。

### 6.6 跳转页面下拉

所有"跳转链接"字段统一渲染为下拉，仅展示运营可读的页面名（如"购物车"、"商品详情页"），可选值：

- 不跳转（`#`）
- 全部 PC 端原型页面（24+ 个）
- 当前若是自定义链接（不在原型清单内），保留一项"自定义链接"防丢失
- 侧边工具条额外提供「回顶部」（`#top`）选项
- 楼层锚点的目标改为"关联楼层"下拉，列出页面主体组件（基于 `id` 与 `group==='page'`）

### 6.7 全局风格面板

通过顶栏「风格设置」进入，配置 `pageTheme`：

| 字段 | 类型 | 说明 |
|---|---|---|
| 背景模式 | 单选 | 纯色 / 背景图 |
| 背景颜色 | color | 纯色模式生效 |
| 背景图片 | 图片选择 | 背景图模式生效 |
| 默认字号 | number | 全站基础字号 |
| 默认文字颜色 | color | 全站基础字色 |
| 主色调 | color | 按钮、链接高亮色（默认 `#e1251b`） |

> Logo 与品牌图片不在此处配置，仍由"搜索头部"组件单独管理，以保留首页/活动页的品牌差异。

## 9. 交互流程

### 9.1 主流程

```
打开搭建器
  → 默认进入「标准首页」，加载默认组件 + 默认主题
  → 在左侧「内置组件」中点击组件 → 右侧加载属性 → 修改后预览实时刷新
  → 风格 / 排序 / 启用隐藏 / 复制楼层 等操作
  → 点击「保存」 → 导出 JSON
  → 点击「发布」 → 确认 → 展示配置汇总
```

### 9.2 多页面流程

```
点击「+ 新建」 → 创建活动子页面
  → 切换到该页面编辑（壳层组件自动跟随首页）
  → 完成后可创建副本 / 重命名 / 删除
  → 在不同页面间切换时自动保存上一个页面状态
```

### 9.3 自动保存机制

- 任何修改（属性输入、列表增删、开关切换、排序、风格调整、楼层复制/删除/重命名）都会触发 `markAutoSaved()`。
- 状态保存在浏览器内存的 `pageStore` / `themeStore` 中；
- 左栏「页面」分栏高度、左右栏折叠状态、缩放比例等本地偏好写入 `localStorage`。

> 注意：当前实现并未将完整配置 JSON 持久化到 localStorage（仅持久化布局偏好）。完整配置导出依赖手动「保存」。

## 10. 数据结构

### 10.1 配置 JSON 主结构

```json
{
  "pageId": "home",
  "pageName": "标准首页",
  "theme": {
    "bgMode": "color",
    "bgColor": "#f4f4f4",
    "bgImg": "",
    "bgImgKey": "",
    "textColor": "#333333",
    "fontSize": 14,
    "primaryColor": "#e1251b"
  },
  "components": [
    {
      "id": "topbar",
      "type": "TopBar",
      "name": "顶部导航栏",
      "group": "page",
      "visible": true,
      "config": { "...": "见 §7" }
    }
  ]
}
```

### 10.2 组件结构字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 组件唯一 id（壳层固定，楼层 `floorN` 自增） |
| `type` | string | 组件类型枚举，见 §7.1 |
| `name` | string | 展示名（楼层会同步为「楼层号 + 标题」） |
| `group` | `'page'` / `'float'` | 分组 |
| `visible` | boolean | 是否启用 |
| `config` | object | 组件配置，结构随 type 变化 |
| `lockedFromHome` | boolean? | 壳层组件在子页面导出时为 true |

### 10.3 图片字段的统一约定

任何图片字段使用 `img` / `imgKey` 双字段：

- `img`：本地上传后的 dataURL 或自定义图片 URL
- `imgKey`：素材库 key（对应 `IMG[key]`）
- 渲染优先级：`img` > `imgKey` > 组件默认占位图

### 10.4 路由兼容

`helpers.js` 维护一份 `LEGACY_ROUTE_TO_PAGE` 映射，把旧语义路径（`/cart`、`/login`、`/activity/nike` 等）统一映射到当前 PC 原型 HTML，确保历史配置 JSON 仍可正确解析。

## 12. 非功能需求

| 维度 | 要求 |
|---|---|
| 性能 | 首屏加载 < 2s；属性修改到预览刷新 < 200ms；同时支持 ≥ 10 个活动子页面 |
| 浏览器 | Chrome / Edge / Firefox 最新两个大版本；不支持 IE；不要求支持移动端浏览器 |
| 分辨率 | 最佳 1920×1080；最低 1440×900（左右栏可收起适配） |
| 可扩展性 | 组件类型可新增（在 `defaults.js` / `TYPE_LABELS` 中登记）；页面模板可扩展 |
| 数据安全 | 完整配置通过 JSON 导出，可由后端读取后渲染；本地上传图片以 dataURL 形式嵌入，不依赖外部图床 |
| 可恢复性 | 提供"恢复默认"；删除/复制均有二次确认 |
| 无障碍 | 主要操作控件具备 `title`；按钮使用 `<button type="button">`；表单 label 与控件绑定 |
